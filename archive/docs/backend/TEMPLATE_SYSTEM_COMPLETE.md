## 🎯 작동 방식

### 새 교재 업로드 시

```
1. PDF 업로드
   ↓
2. OCR 추출 (첫 3-5페이지)
   ↓
3. HybridRouter가 템플릿 매칭 시도
   ↓
   [템플릿 매칭 성공?]
   ├─ YES (신뢰도 85% 이상)
   │   → 템플릿 기반 파서 사용 (2-5초)
   │
   └─ NO
       → AI 파싱 시도 (60-120초)
       → 실패 시 config.json 폴백
```

### 템플릿 관리 워크플로우

```
1. 관리자 페이지 → "템플릿 관리" 클릭
   ↓
2. 템플릿 목록 확인
   ↓
3. 작년 템플릿 복사 (올해 버전 생성)
   ↓
4. 템플릿 편집
   - 패턴 추가/수정
   - 샘플 텍스트로 테스트
   - 패턴 자동 감지 (AI 보조)
   ↓
5. 저장
   ↓
6. 새 교재 업로드 시 자동으로 매칭됨
```

## 🚀 사용 방법

### 1. 템플릿 복사 (작년 → 올해)

```
관리자 페이지 → 템플릿 관리
→ 템플릿 선택 → "복사" 버튼
→ 자동으로 새 버전 생성
```

### 2. 템플릿 편집

```
템플릿 관리 → 템플릿 선택 → "편집" 버튼
→ 패턴 추가/수정
→ 샘플 텍스트로 테스트
→ "저장" 버튼
```

### 3. 패턴 자동 감지

```
템플릿 편집 → 샘플 텍스트 입력
→ "패턴 감지" 버튼
→ 자동으로 패턴 추출 및 추가
```
