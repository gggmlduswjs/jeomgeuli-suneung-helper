# 파싱 진단 가이드

## 문제: 파싱이 잘 되고 있는지 모르겠어요

파싱이 백그라운드에서 실행되기 때문에 진행 상황을 확인하기 어렵습니다.

## 해결: 파싱 진단 스크립트 사용

### 기본 사용법

```bash
cd backend
python scripts/diagnose_parsing.py
```

**특정 교재 진단:**
```bash
python scripts/diagnose_parsing.py {book_id}
```

## 진단 결과 해석

### 1. 파싱 진행 중 (PROCESSING)

**정상적인 경우:**
- 진행률이 계속 증가함
- 페이지가 업데이트됨
- 10분 이내에 완료됨

**문제가 있는 경우:**
- 진행률이 멈춤
- 10분 이상 진행 중
- → **재파싱 필요**

### 2. 파싱 실패 (FAILED)

**원인 1: 강의를 찾지 못함**
```
❌ 강의가 0개입니다.
```
- **원인:**
  - PDF에서 강의 제목을 찾지 못함
  - 강의 제목 패턴이 맞지 않음
  - OCR 품질이 낮음

- **해결:**
  1. 캐시 삭제: `data/{subject}/cache/` 폴더 삭제
  2. 재파싱 시도
  3. `config.json`의 강의 제목 패턴 확인

**원인 2: JSON 파일은 있지만 DB 동기화 실패**
```
✅ JSON 파일 5개 발견
→ JSON 파일은 있지만 DB 동기화가 실패했을 수 있습니다.
→ 'JSON 동기화' 버튼을 클릭하세요.
```
- **해결:** 관리자 페이지에서 "JSON 동기화" 버튼 클릭

**원인 3: 데이터 디렉토리가 없음**
```
❌ 데이터 디렉토리가 없습니다.
→ 파이프라인이 실행되지 않았거나 실패했습니다.
```
- **해결:** 재파싱 시도

### 3. 파싱 완료 (DONE)

**정상:**
```
✅ 파싱이 정상적으로 완료되었습니다!
  - Lesson: 10개
  - Unit: 50개
```

**문제:**
```
⚠️ 경고: Lesson이 0개입니다!
→ JSON 파일은 있지만 DB 동기화가 실패했을 수 있습니다.
→ 'JSON 동기화' 버튼을 클릭하세요.
```

## 자주 발생하는 문제

### 문제 1: 파싱이 멈춤

**증상:**
- 진행률이 멈춤
- 10분 이상 진행 중

**해결:**
1. 재파싱 시도
2. 백엔드 서버 재시작
3. 캐시 삭제 후 재시도

### 문제 2: 강의를 찾지 못함

**증상:**
- 파싱 완료했지만 Lesson이 0개
- JSON 파일이 없음

**해결:**
1. `config.json`의 강의 제목 패턴 확인
2. Tesseract 한국어 언어팩 설치 확인
3. 캐시 삭제 후 재파싱

### 문제 3: JSON 파일은 있지만 DB에 없음

**증상:**
- JSON 파일은 있음
- Lesson이 0개

**해결:**
- 관리자 페이지에서 "JSON 동기화" 버튼 클릭

## 빠른 체크리스트

파싱이 잘 되고 있는지 확인:

1. ✅ **진단 스크립트 실행**
   ```bash
   python scripts/diagnose_parsing.py
   ```

2. ✅ **상태 확인**
   - PROCESSING: 진행 중 (정상)
   - DONE: 완료 (정상)
   - FAILED: 실패 (문제)

3. ✅ **결과 확인**
   - Lesson 개수 확인
   - Unit 개수 확인
   - JSON 파일 확인

4. ✅ **문제 해결**
   - 실패 시: 재파싱
   - JSON만 있는 경우: JSON 동기화
   - 멈춘 경우: 재파싱

## 관련 스크립트

- `diagnose_parsing.py`: 파싱 진단 (추천!)
- `check_parsing_status.py`: 빠른 상태 확인
- `monitor_parsing.py`: 실시간 모니터링
- `check_data.py`: 데이터 확인
