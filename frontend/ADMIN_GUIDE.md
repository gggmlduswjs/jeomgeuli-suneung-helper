# 관리자 페이지 가이드

## 개요

관리자 전용 페이지가 추가되었습니다. 교재 관리, 업로드, 파싱 상태 모니터링을 한 곳에서 할 수 있습니다.

## 접근 방법

### 관리자 페이지 (`/admin`)
- **경로**: `http://localhost:5173/admin`
- **접근**: 
  - 메인 페이지(`/main`)에서 "관리자 페이지" 버튼 클릭
  - 직접 URL 입력: `/admin`

## 관리 기능 접근 방법

### 🎯 권장: 관리자 페이지 (`/admin`)
- **경로**: `http://localhost:5173/admin`
- **접근**: 메인 페이지(`/main`)에서 "관리자 페이지" 버튼 클릭
- **기능**:
  - 교재 목록 및 통계 대시보드
  - 교재 업로드
  - 재파싱, 삭제, JSON 동기화
  - 파싱 상태 실시간 모니터링

### 기타 접근 방법 (호환성 유지)

#### 교재 선택 페이지 (`/books`)
- **경로**: `http://localhost:5173/books`
- **기능**:
  - **키보드**: `+` 키를 눌러 새 교재 추가
  - **마우스**: "새 교재 추가" 버튼 클릭
  - 교재 목록 확인, 삭제, 재파싱

#### 교재 페이지 (`/book`)
- **경로**: `http://localhost:5173/book` (bookId 없이)
- **기능**: PDF 업로드 폼 표시

## 관리자 페이지 기능

### 대시보드
- **통계 카드**: 전체 교재 수, 완료, 진행 중, 실패
- **총 강의 수**: 모든 교재의 강의 수 합계

### 교재 관리 기능

#### 교재 업로드
1. 관리자 페이지에서 "새 교재 업로드" 버튼 클릭
2. PDF 파일 선택
3. 교재 정보 입력:
   - 제목
   - 과목 (KOREAN, MATH, ENGLISH)
   - 연도 (선택)
4. AI 처리 옵션 설정 (선택)
5. 업로드 버튼 클릭

#### 교재 재파싱
- **위치**: 관리자 페이지 (`/admin`)
- **조건**: 파싱 실패(`FAILED`) 또는 강의가 없는 교재
- **방법**: 교재 카드의 "재파싱" 버튼 클릭

#### 교재 삭제
- **위치**: 관리자 페이지 (`/admin`)
- **방법**: 교재 카드의 "삭제" 버튼 클릭
- **확인**: 삭제 확인 다이얼로그 표시

#### JSON 동기화
- **위치**: 관리자 페이지 (`/admin`)
- **기능**: JSON 파일이 생성되었지만 DB에 저장되지 않은 경우 동기화
- **방법**: 교재 카드의 "JSON 동기화" 버튼 클릭
- **자동**: 파싱 완료 후 강의가 없으면 자동으로 시도

## 관리자 페이지 특징

### 실시간 모니터링
- 파싱 진행 상태 자동 업데이트 (10초마다)
- 파싱 완료/실패 시 자동 알림
- 재파싱 진행률 표시

### 통계 대시보드
- 전체 교재 수
- 완료/진행 중/실패 교재 수
- 총 강의 수

### 직관적인 UI
- 상태별 아이콘 및 색상 구분
- 교재별 액션 버튼 (JSON 동기화, 재파싱, 삭제)
- 반응형 디자인

## 관리 기능 상세

### PDF 업로드 프로세스

1. **파일 업로드**
   - `POST /api/books/upload` API 호출
   - 백그라운드에서 자동 파싱 시작

2. **파싱 상태 확인**
   - `GET /api/books/{book_id}/parse-status` API로 진행률 확인
   - 프론트엔드에서 10초마다 자동 폴링

3. **파싱 완료**
   - 자동으로 DB에 커리큘럼 및 Lesson 생성
   - 교재 목록에 표시

### 파싱 상태

- **PROCESSING**: 파싱 진행 중
- **DONE**: 파싱 완료 (사용 가능)
- **FAILED**: 파싱 실패 (재파싱 필요)
- **PENDING**: 대기 중

## API 엔드포인트

### 교재 관리
- `POST /api/books/upload` - PDF 업로드
- `GET /api/books` - 교재 목록
- `GET /api/books/{book_id}` - 교재 상세
- `GET /api/books/{book_id}/parse-status` - 파싱 상태
- `POST /api/books/{book_id}/reparse` - 재파싱
- `POST /api/books/{book_id}/sync-from-json` - JSON 동기화
- `DELETE /api/books/{book_id}` - 교재 삭제

## 권장 워크플로우

### 새 교재 추가
1. `/books` 페이지 접속
2. `+` 키 또는 "새 교재 추가" 버튼 클릭
3. PDF 파일 선택 및 정보 입력
4. 업로드 후 파싱 완료 대기 (1-2분)
5. 파싱 완료 후 교재 사용 가능

### 파싱 실패 시
1. `/books` 페이지에서 실패한 교재 확인
2. 교재 선택 후 `r` 키로 재파싱
3. 또는 `/book/{book_id}` 페이지에서 "재파싱" 버튼 클릭

## 참고

- 모든 관리 기능은 인증 없이 접근 가능 (개발 환경)
- 프로덕션 환경에서는 인증/권한 체계 추가 필요
- 파싱은 백그라운드에서 비동기로 처리됨
- 대용량 PDF는 처리 시간이 오래 걸릴 수 있음 (페이지당 약 5-10초)
