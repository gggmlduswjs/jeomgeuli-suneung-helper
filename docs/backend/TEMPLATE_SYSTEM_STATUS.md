# 템플릿 시스템 현황 및 계획

## ✅ 완료된 것

### 1. 템플릿 관리 API
- **파일:** `backend/app/routers/templates.py`
- **엔드포인트:**
  - `GET /api/v1/templates` - 템플릿 목록
  - `GET /api/v1/templates/{subject}/{name}` - 템플릿 상세
  - `POST /api/v1/templates` - 템플릿 생성
  - `PUT /api/v1/templates/{subject}/{name}` - 템플릿 수정
  - `DELETE /api/v1/templates/{subject}/{name}` - 템플릿 삭제
  - `POST /api/v1/templates/{subject}/{name}/copy` - 템플릿 복사
  - `POST /api/v1/templates/{subject}/{name}/test` - 템플릿 테스트
  - `POST /api/v1/templates/detect-patterns` - 패턴 자동 감지 (AI 보조)

### 2. 프론트엔드 서비스
- **파일:** `frontend/src/services/templates.ts`
- 템플릿 API 호출 함수들

### 3. 템플릿 관리 UI (기본)
- **파일:** `frontend/src/components/admin/TemplateManager.tsx`
- 템플릿 목록, 복사, 삭제 기능
- 관리자 페이지에 "템플릿 관리" 버튼 추가

## 📝 사용 방법

### 1. 템플릿 목록 확인
```
관리자 페이지 → "템플릿 관리" 버튼 클릭
```

### 2. 템플릿 복사 (작년 → 올해)
```
템플릿 관리 → 템플릿 선택 → "복사" 버튼
→ 자동으로 새 버전 생성
```

### 3. 템플릿 테스트
```
템플릿 관리 → 템플릿 선택 → "테스트" 버튼
→ 샘플 텍스트 입력 → 패턴 매칭 결과 확인
```
