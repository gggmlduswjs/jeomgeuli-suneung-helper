## 📋 구현 계획

### Phase 1: 템플릿 시스템 통합 (현재 진행 중)

**현재 상태:**
- ✅ 템플릿 시스템 존재 (`TemplateManager`, `ParsingTemplate`)
- ✅ 템플릿 파일 저장 (`data/templates/*.json`)
- ⚠️ 파이프라인은 여전히 `config.json` 사용
- ⚠️ 템플릿과 config.json이 분리되어 있음

**해야 할 일:**
1. 파이프라인이 템플릿을 직접 사용하도록 수정
2. `config.json` → 템플릿 자동 변환 유지
3. 템플릿 매칭 자동화 (새 교재 업로드 시)

### Phase 2: 템플릿 관리 API (1주)

**엔드포인트:**
```python
GET    /api/v1/templates              # 템플릿 목록
GET    /api/v1/templates/{id}         # 템플릿 상세
POST   /api/v1/templates              # 템플릿 생성
PUT    /api/v1/templates/{id}         # 템플릿 수정
DELETE /api/v1/templates/{id}        # 템플릿 삭제
POST   /api/v1/templates/{id}/copy    # 템플릿 복사
POST   /api/v1/templates/{id}/test    # 템플릿 테스트
```

**기능:**
- 템플릿 CRUD
- 작년 템플릿 복사
- 샘플 PDF로 테스트

### Phase 3: 템플릿 설정 UI (2주)

**관리자 페이지에 추가:**

```
┌─────────────────────────────────────┐
│ 템플릿 관리                          │
├─────────────────────────────────────┤
│                                     │
│ [1] 템플릿 목록                      │
│   - literature_ebs_수능특강_2026    │
│   - english_ebs_수능특강_2026       │
│                                     │
│ [2] 새 템플릿 만들기                 │
│   - 작년 템플릿 복사                 │
│   - 새로 만들기                      │
│                                     │
│ [3] 템플릿 편집                      │
│   - 패턴 추가/수정                   │
│   - 샘플로 테스트                    │
│                                     │
└─────────────────────────────────────┘
```

**템플릿 편집 UI:**
```
┌─────────────────────────────────────┐
│ 템플릿 편집: ebs_수능특강_영어_2026 │
├─────────────────────────────────────┤
│                                     │
│ 강의 제목 패턴:                     │
│ [  "^\\d+강"  ] [추가] [삭제]      │
│ [  "^\\d{2}강" ] [추가] [삭제]     │
│                                     │
│ 문제 번호 패턴:                     │
│ [  "^\\d+\\."  ] [추가] [삭제]     │
│                                     │
│ 샘플 텍스트:                        │
│ ┌─────────────────────────────────┐ │
│ │ 1강 글의 목적 파악              │ │
│ │ 1. 다음을 듣고...               │ │
│ └─────────────────────────────────┘ │
│                                     │
│ [패턴 추천] ← AI 보조 기능          │
│ [테스트] [저장]                    │
│                                     │
└─────────────────────────────────────┘
```

### Phase 4: 자동 템플릿 매칭 (1주)

**새 교재 업로드 시:**
```python
1. PDF 첫 3페이지 추출
2. 기존 템플릿과 매칭
3. 신뢰도 85% 이상 → 자동 사용
4. 신뢰도 85% 미만 → 템플릿 선택 UI 표시
```

### Phase 5: AI 보조 기능 (선택)

**AI는 보조만:**
```python
1. 패턴 추천 (새 템플릿 만들 때)
   - 샘플 텍스트 분석
   - 자주 나오는 패턴 제안
   
2. 이상 탐지 (파싱 결과 검증)
   - 강의가 0개 → 경고
   - 패턴이 이상함 → 제안
   
3. 자동 완성 (편집 중)
   - 패턴 입력 시 자동 완성
```
