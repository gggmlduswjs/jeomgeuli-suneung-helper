# 프로젝트 결과 요약

## 핵심 기능

1. **PDF 자동 파싱**: 템플릿 기반 + AI 구조 분석으로 강의 목록 자동 추출
2. **점자 변환/연동**: 한글점자규정 준수, BLE 하드웨어(Orbit Reader 20) 연동
3. **AI 학습 도우미**: GPT-4o-mini 질의응답, RAG 기반 유사 콘텐츠 추천
4. **음성 인터페이스**: Web Speech API 기반 STT/TTS, 음성 명령 지원
5. **학습 관리**: 개념-본문-문제 순차 학습, 카드 스와이프 UI, 진도 추적
6. **관리자 기능**: AI 기반 템플릿 생성, PDF 업로드/파싱 자동화
7. **수능 환경 반영**: 텍스트 찾기(Ctrl+F), 수식 계산 도구, 특수문자 변형 처리
