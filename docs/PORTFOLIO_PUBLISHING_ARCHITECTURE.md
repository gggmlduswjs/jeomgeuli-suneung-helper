## 📌 콘텐츠 역량 한 페이지 요약 (면접·발표용)

**이 포트폴리오가 보여주는 콘텐츠 역량 (4가지)**

| 역량 | 내용 | 이 포트폴리오에서의 근거 |
|------|------|---------------------------|
| **① 학습 흐름·시리즈 기획** | 대상·단계별로 역할을 나누고, 교재 간 연결 구조를 설계한다. | 배움–키움–이룸 3단계 재정의, 컴놀이 1·2·3권 역할 분리, 키움 재포지셔닝 |
| **② 차시·목차 설계** | "기능 나열"이 아닌 **경험·집중도·성장** 순서로 목차를 짠다. | 조작 안정 → 탐색·흥미 → 창작 몰입, AI 후반 배치, "해봤다"가 남도록 구성 |
| **③ 지면·자료 구조화** | 교재와 수업이 끊기지 않도록 **공통 지면 + PPT**로 틀을 고정한다. | 도입–활동–정리, 교재–PPT 1:1, 한 화면에 하나의 행동만 |
| **④ "쓰일 때 완성" 관점** | "무엇을 만들까"보다 **"어떻게 쓰일까"**를 먼저 설계한다. | 수업용 PPT·표지 전략·정규 수업 활용 포지셔닝까지 연계 |

**핵심 설계 원칙 (의사결정 근거)**  
- **대상 우선**: 연령·인지·경험 수준 → 그다음 단계·목차·활동 순서  
- **경험 > 설명**: 저학년은 "가르치기"보다 "친해지기", 기능보다 결과물·맥락  
- **AI = 조력자**: 개념 설명으로 두지 않고, 조작·창작 경험 뒤 "확장 도구"로 배치  
- **형식 고정, 내용 집중**: 지면·PPT 구조를 통일해 학습자·교사가 매 차시 흐름을 예측하게 함  

→ **콘텐츠 역량이 뛰어나다**는 인상을 주려면, **위 4가지 역량**과 **설계 원칙**을 발표 초반(1–2장)에서 먼저 드러내고, 이어지는 01–07이 "그래서 이렇게 설계·실행했다"는 **근거**로 읽히도록 구성하는 것이 좋습니다.

┌─────────────────────────────────────────────────────────────────────┐
│ 핵심 설계 철학                                                       │
└─────────────────────────────────────────────────────────────────────┘
        │
        ├─→ **"경험 → 확장" 철학**
        │       │
        │       └─→ AI는 후반에 배치: 먼저 조작·활용·창작을 경험한 뒤,
        │           AI가 그 경험을 확장하는 도구로 배치
        │           "AI가 대신 만든다" ❌ → **"내가 한 것을 AI가 도와준다"** ⭕
        │
        ├─→ **"친해지기 → 알아보기 → 만들기" 흐름**
        │       │
        │       └─→ 저학년은 "가르치기"보다 "친해지기" 우선
        │           기능 설명보다 활동·놀이·결과물 중심
        │
        ├─→ **"기능 나열"이 아닌 "경험 순서"**
        │       │
        │       └─→ "마우스 사용법" ❌ → **"마우스야 나랑 놀래?"** ⭕
        │           기능 중심이 아니라 학습자의 경험·맥락 중심
        │
        ├─→ **"차시당 하나의 결과물"**
        │       │
        │       └─→ 매 차시마다 "해봤다/만들었다"는 성취감 제공
        │           "공부"가 아니라 "만들기"로 동기 부여
        │
        └─→ **"배움–키움–이룸" 네이밍 철학**
                │
                └─→ "초급·중급·고급" ❌ → **"배움–키움–이룸"** ⭕
                    자연의 성장(씨앗 → 가꾸기 → 열매)에 비유
                    **"지금 어디쯤 성장하고 있는가"**를 긍정적으로 인식
        │
        ▼
┌─────────────────────────────────────────────────────────────────────┐
│ 핵심 철학 한 줄                                                      │
└─────────────────────────────────────────────────────────────────────┘
        │
        └─→ **"컴퓨터를 가르치기보다, 먼저 친해지게 하고,
            내가 만든 결과물을 통해 '할 수 있다'는 경험을 주는 것"**
```

**슬라이드 하단 한 줄**
> "기능을 나열하는 교재가 아니라, 학습자의 성장 흐름에 맞춰 경험을 설계한 교재입니다."

└─────────────────────────────────────────────────────────────────────┘
        │
        ├─→ 차시당 1:1 수업용 PPT 제작 (도입–활동–정리 연동)
        └─→ 교재–PPT–실습 흐름 맞춤, 교사가 수업에 바로 사용 가능

**요약 한 줄**
> **5월 기획 → 6–8월 키움 원고·편집 → 8월 전환점 → 10월 키움 완료 → 10–11월 컴놀이 원고·편집 → 표지 제작(숨고 협업) → 2월 출간(교보·YES24) → 3월 PPT**  
> "설계만 한 것이 아니라, **만들고·출간하고·쓰이게**까지 이어갔습니다."

**슬라이드 하단 한 줄**
> "기획부터 유통·학습 자료까지, **실제 출간 과정**을 한 흐름으로 진행했습니다."

## 📌 콘텐츠 역량이 잘 보이게 하는 구성·발표 팁

**1. 순서**  
- **앞쪽**에 「콘텐츠 역량 한 페이지 요약」 배치 → "이 사람 역량이 뭐지?"를 먼저 답하게 한다.  
- 이어서 01 개요 → 02 시리즈 전략 → 03–05 설계 상세 → **06 출간 과정** → **07 결과** 순서로 **"원칙 → 실행 → 성과"**가 이어지도록.

**2. 슬라이드별로 역량 키워드 노출**  
- 01: "시리즈 기획·학습 단계 재설계"  
- 02: "대상 기반 3단계 구조, 콘텐츠 재배치"  
- 03: "차시·목차 설계, 경험 순서, AI 배치"  
- 04: "재포지셔닝, 기본기 축적"  
- 05: "지면·표지·PPT 구조화, 교재–수업 연결" *(공통 설계 요소)*  
- 06: "**실제 출간 과정** (기획→편집→인쇄→등록→유통→학습자료), 실행력"  
- 07: "기획→편집→출판→유통(교보·YES24)→수업 활용까지 연결, 결과 정리"  
→ 매 장에서 **위 4가지 역량** 중 무엇을 보여주는지 한 줄씩만 넣어도 "콘텐츠 역량" 인상이 강해진다.

**3. "왜 그렇게 했는가"를 꼭 넣기**  
- AI 후반 배치, 경험 중심 목차, 도입–활동–정리 고정 등 **의사결정 근거**를 짧게라도 적는다.  
- "그냥 그렇게 했다"가 아니라 **"대상·목표 때문에 이렇게 선택했다"**가 보이면 역량이 구체적으로 전달된다.

**4. Before/After나 1–2개 구체 예시**  
- 가능하면 **기존(기획 없음) vs 재설계 후**를 1–2例만이라도 비교해서 보여준다.  
- 예: "기능 나열 목차 → 경험 순서 목차", "과목별 난립 → 배움–키움–이룸 연결" 등.  
→ **설계 전·후 차이**가 보일수록 역량이 잘 드러난다.

**5. 면접 시 "콘텐츠 역량" 강조용 1분 멘트**  
> "저는 교재를 **만드는** 역할이 아니라, **학습이 흐르도록 설계하는** 역할에 강점이 있습니다. 이번 프로젝트에서는 기획이 없이 흩어져 있던 교재들을 **배움–키움–이룸** 구조로 재설계하고, 차시별로 **경험 순서·집중도·AI 배치**까지 고민해서 목차를 잡았습니다. **도입–활동–정리** 지면 구조와 **수업용 PPT**까지 이어서, 교재만 보고도 수업이 돌아가도록 맞춰두었고, 그 결과물을 **교보문고·YES24에 실제 출간**까지 마쳤습니다. 결국 **‘무엇을 만들까’보다 ‘어떻게 쓰일까’**를 먼저 설계하는 편입니다."

| "교재를 **쓰는** 순간까지 생각해서 설계하는 편입니다." | 쓰일 때 완성 관점 강조 |
| "대상과 단계를 먼저 정하고, 그다음에 목차와 지면을 설계합니다." | 대상 우선 원칙 강조 |

→ 위 중 하나를 **인트로 직후** 또는 **07 포트폴리오 메시지** 위에 두면 "콘텐츠 역량 + 나만의 포지션"이 동시에 전달된다.

---

### 2. 숫자·규모 (가능한 범위에서)

| 항목 | 예시 | 넣을 위치 |
|------|------|-----------|
| 권수·종수 | 컴놀이 3권, 키움 6종 등 | 01 개요, 03·04 시리즈 |
| 차시·단원 수 | 권당 24차시, 단원당 N쪽 등 | 03 배움 시리즈 |
| PPT·자료 수 | 차시당 1 PPT, 총 N개 등 | 05 공통 설계 |
| 기간·마일스톤 | 2024.03–2025.03, 키움 개정 완료 시점 등 | 01 개요 |
| 보급·활용 | "N개 학교", "정규 수업 채택" 등 (있다면) | 07 결과 |

→ **구체적 숫자**가 들어가면 "실제로 이만큼 했다"는 인상이 커진다. 없는 것은 무리해서 쓰지 않아도 된다.

---

### 3. 예상 Q&A 2–3개

면접·자문 시 자주 나올 수 있는 질문에 대한 **짧은 답 요약**을 적어두면 유리하다.

| 질문 | 답 요약 (1–2문장) |
|------|-------------------|
| **가장 어려웠던 점은?** | 예: "기존 원고(컴여행)를 '그대로 출간'이 아닌 '배움 시리즈에 맞게 재구성'하는 선을 정하는 것. 저학년 경험 순서와 강사 원고의 균형을 맞추느라 목차를 여러 번 바꿨습니다." |
| **타협하거나 포기한 부분은?** | 예: "AI를 1권 앞쪽에 두고 싶다는 의견도 있었지만, '조작·창작 경험 선행' 원칙을 지키기 위해 후반 배치로 맞췄습니다." |
| **다시 한다면 / 다음에는?** | 예: "이룸 시리즈를 구조 단계에서 구체 목차·지면까지 설계하고, 배움·키움 출간 후 현장 피드백을 받아 개정 반영하는 단계까지 이어가고 싶습니다." |

→ **어려움·타협·다음 단계**를 말할 수 있으면 **성찰·협업·추진력**이 같이 전달된다.

---

### 4. 한계·다음 단계 (1–2문단)

07 결과 또는 부록에 **아주 짧게** 넣을 수 있다.

- **이룸**: 현재 구조 설계 단계까지 → 구체 목차·원고·출간 일정은 이후 단계.
- **미처 못 다룬 점**: 예) "특정 학교·학급 규모별 맞춤 보조 자료", "교사 연수용 가이드" 등 (해봤다면 그걸, 못 했다면 "다음 과제로 두고 있다" 정도만).
- **개선하고 싶은 점**: 예) "표지·지면 샘플을 더 많이 확보해, '설계 원칙 → 실제 산출물' 매칭을 보여주고 싶다" 등.

→ **한계를 인정하고 다음을 말하는** 모습은 역량을 깎아내리지 않으면서 **현실 감각**을 보여준다.

---

### 5. 산출물 연결 (목차·표지·지면 샘플)

- **세부 목차**, **표지 시안**, **도입–활동–정리 지면 샘플** 등 **실제 산출물**이 있으면:
  - "상세 목차는 [별도 문서·링크]"  
  - "표지·지면 샘플은 [부록·첨부]"  
처럼 **어디서 볼 수 있는지**를 03·05 쪽에 한 줄씩 넣어두면 좋다.
- **구조**만 있고 **결과물**이 보이지 않으면, "실제로 이렇게 나왔다"는 느낌이 덜할 수 있다.

---

### 6. 협업·소통 (선택)

- **원고 작성자(강사)·출판·인쇄** 등과 **역할을 나누고 어떻게 맞춰 갔는지**를 1–2문장으로 보태도 된다.
- 예: "원고는 OOO 님, 기획·목차·지면 구조·PPT는 제가 맡아서, 교재–수업 연결까지 한 흐름으로 맞췄습니다."
- **"나 혼자 다 했다"**가 아니라 **"기획·설계를 주도하고, 필요한 부분은 협력**"이라는 뉘앙스가 드러나면, **협업 역량**도 자연스럽게 보인다.

---

**정리**:  
- **꼭 넣으면 좋은 것**: (1) "왜 전희연인가?" 한 줄, (3) 예상 Q&A 2–3개.  
- **자료 있으면 보강**: (2) 숫자·규모, (5) 산출물 연결.  
- **여유 있으면**: (4) 한계·다음 단계, (6) 협업·소통.
