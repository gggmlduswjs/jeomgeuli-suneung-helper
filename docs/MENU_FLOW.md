## 사용자 여정 (User Journey)

### 시나리오 1: 처음 시작하는 학습자

```
홈 화면 (/)
    │
    ├─→ 과목 선택 (국어/영어/수학)
    │       │
    │       └─→ 교재 목록 (/book?subject={subject})
    │               │
    │               └─→ 교재 선택
    │                       │
    │                       └─→ 커리큘럼 목록 (/curriculum/{curriculumId})
    │                               │
    │                               └─→ 1강 클릭
    │                                       │
    │                                       └─→ 학습 화면 (/lesson/{lessonId})
    │                                               │
    │                                               ├─→ 레슨 목록 (레슨 1, 2, 3...)
    │                                               ├─→ 레슨 상세 (청크 단위 읽기)
    │                                               ├─→ PDF 참조
    │                                               └─→ 문제 풀기
    │                                                       │
    │                                                       └─→ 복습
```

### 시나리오 2: 이어서 학습하는 학습자

```
홈 화면 (/)
    │
    └─→ 오늘 학습 이어하기
            │
            └─→ 학습 화면 (마지막 위치)
                    │
                    ├─→ 이전 레슨
                    │
                    ├─→ 현재 레슨 계속
                    │
                    └─→ 다음 레슨
```

### 시나리오 3: 문제 풀이 중심 학습자

```
홈 화면 (/)
    │
    └─→ [하단 탭: 문항]
            │
            └─→ 문제 풀이 화면 (/question)
                    │
                    ├─→ 문제 풀기
                    │       │
                    │       └─→ 답안 제출
                    │               │
                    │               ├─→ 정답 → 다음 문제
                    │               │
                    │               └─→ 오답 → 해설 보기 → 오답 노트
                    │
                    └─→ 오답 노트
                            │
                            └─→ 복습 화면 (/review)
                                    │
                                    └─→ 복습 문제 풀기
```

### 시나리오 4: 어휘 학습 중심 학습자

```
홈 화면 (/)
    │
    └─→ [하단 탭: 어휘]
            │
            └─→ 어휘 학습 화면 (/vocab)
                    │
                    ├─→ 일반 어휘
                    │       │
                    │       └─→ 어휘 카드 학습
                    │
                    └─→ 시사 어휘
                            │
                            └─→ 시사 어휘 카드 학습
```

### 시나리오 5: 시험 모드 학습자

```
홈 화면 (/)
    │
    └─→ [하단 탭: 시험]
            │
            └─→ 시험 모드 화면 (/exam-mode)
                    │
                    └─→ 시험 시작
                            │
                            └─→ 시험 타이머 (/exam-timer)
                                    │
                                    └─→ 문제 풀이 (시험 모드)
                                            │
                                            └─→ 시험 제출
                                                    │
                                                    └─→ 시험 결과
```

## 하단 탭 네비게이션

**중요**: 모든 화면 하단에 고정된 탭 네비게이션이 있어 언제든지 주요 화면으로 이동 가능합니다.

```
┌─────────────────────────────────────────────────────────────┐
│                                                             │
│                    [현재 화면 내용]                         │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│  [홈]  [교재]  [문항]  [어휘]  [시험]                       │
│   ↑     ↑      ↑      ↑      ↑                             │
│   │     │      │      │      │                             │
│   └─────┴──────┴──────┴──────┴─────────────────────────────┘
│   언제든지 탭을 눌러 해당 화면으로 이동 가능
└─────────────────────────────────────────────────────────────┘
```

### 탭 네비게이션 특징

- **항상 접근 가능**: 모든 화면에서 하단 탭으로 주요 기능 접근
- **현재 위치 표시**: 활성화된 탭은 하이라이트 표시
- **빠른 전환**: 한 번의 탭으로 주요 화면 이동
- **음성 명령 지원**: 탭 이름을 말하면 해당 화면으로 이동

### 탭별 이동 경로

#### 1. 홈 탭
```
[홈] → 홈 화면 (/)
```

#### 2. 교재 탭
```
[교재] → 교재 관리 화면 (/textbook)
            │
            ├─→ 교재 목록
            │
            ├─→ 교재 상세 (/book/{bookId})
            │       │
            │       └─→ 레슨 목록
            │               │
            │               └─→ 레슨 상세 (/lesson/{lessonId})
            │                       │
            │                       └─→ 학습 화면
            │
            └─→ 단원 상세 (/unit/{unitId})
                    │
                    └─→ 학습 화면
```

#### 3. 문항 탭
```
[문항] → 문제 풀이 화면 (/question)
            │
            ├─→ 문제 풀이
            │
            └─→ 오답 노트
                    │
                    └─→ 오답 문제 다시 풀기
```

#### 4. 어휘 탭
```
[어휘] → 어휘 학습 화면 (/vocab)
            │
            ├─→ 일반 어휘
            │
            └─→ 시사 어휘
```

#### 5. 시험 탭
```
[시험] → 시험 모드 화면 (/exam-mode)
            │
            ├─→ 시험 시작
            │
            └─→ 시험 타이머 (/exam-timer)
```

### 주요 화면 계층 구조

```
홈 화면 (/)
│
├─→ 오늘 학습 이어하기
│   └─→ 학습 화면 (/learning)
│       └─→ 레슨 상세 (/lesson/{lessonId})
│
├─→ 과목 선택
│   ├─→ 국어 → 교재 목록 (/book?subject=korean)
│   ├─→ 영어 → 교재 목록 (/book?subject=english)
│   └─→ 수학 → 교재 목록 (/book?subject=math)
│       │
│       └─→ 교재 선택
│           │
│           └─→ 커리큘럼 목록 (/curriculum/{curriculumId})
│               │
│               └─→ 1강 클릭
│                   │
│                   └─→ 학습 화면 (/lesson/{lessonId})
│                       │
│                       ├─→ 레슨 상세 (레슨 목록 구성)
│                       ├─→ PDF 참조
│                       └─→ 문제 풀기
│
└─→ 교재 관리
    └─→ 교재 관리 화면 (/textbook)
        ├─→ PDF 업로드
        └─→ 교재 목록

[하단 탭 네비게이션 - 모든 화면에서 접근 가능]
│
├─→ [홈] → 홈 화면 (/)
│
├─→ [교재] → 교재 관리 화면 (/textbook)
│       ├─→ 교재 목록
│       ├─→ 교재 상세 (/book/{bookId})
│       │       └─→ 레슨 목록
│       │           └─→ 레슨 상세 (/lesson/{lessonId})
│       │                   └─→ 학습 화면
│       └─→ 단원 상세 (/unit/{unitId})
│               └─→ 학습 화면
│
├─→ [문항] → 문제 풀이 화면 (/question)
│       ├─→ 문제 풀이
│       └─→ 오답 노트
│               └─→ 복습 화면 (/review)
│
├─→ [어휘] → 어휘 학습 화면 (/vocab)
│       ├─→ 일반 어휘
│       └─→ 시사 어휘
│
└─→ [시험] → 시험 모드 화면 (/exam-mode)
        ├─→ 시험 시작
        └─→ 시험 타이머 (/exam-timer)

[제작자용]
│
└─→ 커리큘럼 관리 화면 (/curriculum)
        ├─→ 커리큘럼 목록
        │       └─→ 커리큘럼 상세
        │               ├─→ 학습 경로 시각화
        │               ├─→ 레슨 목록
        │               │       └─→ 레슨 상세
        │               │               ├─→ 섹션 목록
        │               │               ├─→ 학습 단위 목록
        │               │               └─→ PDF 참조 정보
        │               └─→ 레슨 간 연결
        │
        └─→ 새 커리큘럼 생성
                ├─→ 기본 정보 입력
                ├─→ 강의대본 업로드
                ├─→ PDF 파일 업로드 (선택)
                └─→ 커리큘럼 생성
```

## 음성 명령 네비게이션

모든 화면에서 음성 명령으로 네비게이션 가능:

| 음성 명령 | 이동 경로 |
|----------|----------|
| "홈" | 홈 화면 (/) |
| "교재" | 교재 관리 화면 (/textbook) |
| "문항" | 문제 풀이 화면 (/question) |
| "어휘" | 어휘 학습 화면 (/vocab) |
| "시험" | 시험 모드 화면 (/exam-mode) |
| "복습" | 복습 화면 (/review) |
| "이어하기" | 마지막 학습 위치로 이동 |
| "국어", "영어", "수학" | 해당 과목 교재 목록 |
| "뒤로" | 이전 화면으로 이동 |

## 화면 간 전환 규칙

### 1. 학습 흐름
```
홈 → 교재 선택 → 레슨 선택 → 학습 화면 → 문제 풀기 → 복습
```

### 2. 문제 풀이 흐름
```
문제 풀이 → 답안 제출 → 결과 확인 → 다음 문제 / 오답 노트
```

### 3. 복습 흐름
```
복습 화면 → 복습 문제 선택 → 문제 풀이 → 복습 완료
```

### 4. 시험 흐름
```
시험 모드 → 시험 시작 → 문제 풀이 → 시험 제출 → 결과 확인
```
