# 개발 로드맵 (Development Roadmap)

점글이 수능 헬퍼 프로젝트의 전체 개발 순서와 우선순위를 정리한 문서입니다.

> **현재 상태 (2024년 기준)**: Phase 0 약 60% 완료

---

## 📍 현재 완료 상태

### ✅ 완료된 기능

1. **PDF 추출 및 파싱 인프라** (100%)
   - PDF 블록 추출 (pdfplumber 기반)
   - 과목별 파서 (Math1, Literature, English)
   - 파싱 파이프라인 및 JSON 저장

2. **점자 변환** (100% - 규칙 기반)
   - 한글→점자 규칙 기반 변환
   - 약자 처리

3. **한글 파일 처리** (100%)
   - HWP 파일 텍스트 추출
   - 파일명에서 강의 정보 추출

4. **강의 대본 파서** (100%)
   - 대본 섹션 분류 (OT, Overview, Concept 등)
   - 핵심 포인트 및 수학 표현식 추출
   - API 엔드포인트 제공

5. **제작 자동화 기본 구조** (50%)
   - 기본 클래스 구조 완료
   - 말하는 단위 분할 로직 완료

---

## 🗺 전체 개발 순서

### Phase 0: 데이터 인프라 및 제작 자동화 (현재 진행 중 - 60% 완료)

**목표**: 제작 시간 단축 및 데이터 수집 인프라 구축

#### 0.1 한글 파일 업로드 API 구현 ⭐⭐⭐ (1주)

**왜 필요한가?**
- 현재 텍스트 추출 기능만 있고, 실제 파일 업로드 기능이 없음
- 제작자들이 한글 파일을 직접 업로드하여 처리 가능해야 함

**해야 할 일:**
- [ ] `POST /api/v1/books/upload-hwp` 엔드포인트 구현
- [ ] 파일 업로드 처리 및 임시 저장
- [ ] 자동으로 텍스트 추출 및 구조 파싱
- [ ] 데이터베이스에 저장 (Book, Lesson 엔티티)
- [ ] 프론트엔드 업로드 UI 연동

**완료 기준:**
- 한글 파일을 업로드하면 자동으로 강의 구조가 파싱되어 DB에 저장됨
- 교재 관리 화면에서 한글 파일 기반 교재 목록 확인 가능

---

#### 0.2 제작 프로세스 자동화 완성 ⭐⭐⭐⭐⭐ (2주)

**왜 필요한가?** (최우선순위)
- 제작 시간 80% 단축 목표
- 사용자 확대의 핵심 (더 많은 강의 제공 가능)

**해야 할 일:**
- [ ] `ContentAutoGenerator` 클래스 완성
  - [ ] 매뉴얼 규칙 완전 자동 적용
  - [ ] 기호 사용 규칙 자동 검증 및 수정
  - [ ] 정보 순서 자동 최적화
  - [ ] 텍스트 길이 자동 조절 (말하는 단위)
- [ ] 제작 검증 시스템 구현
  - [ ] 품질 점수 자동 계산
  - [ ] 개선 제안 자동 생성
- [ ] API 엔드포인트 추가
  - [ ] `POST /api/v1/content/generate` - 자동 제작
  - [ ] `POST /api/v1/content/validate` - 검증
- [ ] 웹 UI에서 사용 가능하도록 통합

**완료 기준:**
- 한글 파일을 업로드하면 자동으로 매뉴얼 규칙을 적용한 학습 자료 생성
- 제작자가 검수 시간을 80% 단축 가능
- 품질 점수 90점 이상 달성

---

#### 0.3 강의 대본 파서 프론트엔드 통합 ⭐⭐⭐ (1주)

**왜 필요한가?**

**해야 할 일:**
- [ ] 대본 업로드 UI 컴포넌트
- [ ] 파싱 결과 시각화
- [ ] 섹션별 보기 기능
- [ ] 핵심 포인트 요약 표시

**완료 기준:**
- 웹 UI에서 대본을 업로드하고 파싱 결과를 확인할 수 있음

#### 0.4 PDF 구조화 추출 UI/UX 구현 ⭐⭐⭐⭐ (2-3주)

**왜 필요한가?**

**해야 할 일:**
- [ ] `QuestionViewer` 컴포넌트 (프론트엔드)
  - [ ] 문제/본문/선택지 구조화 표시
  - [ ] 원본 이미지 표시 기능
  - [ ] 텍스트/이미지/둘 다 보기 모드
- [ ] `PassageViewer` 컴포넌트 (프론트엔드)
  - [ ] 본문 표시
  - [ ] 원본 이미지 표시
- [ ] 점자 통합
  - [ ] 문제/본문/선택지 점자 변환
  - [ ] 점자 디바이스 연동
- [ ] 기존 `UnitContent`와 통합

**완료 기준:**
- PDF를 업로드하면 구조화된 문제/본문이 표시됨
- 원본 이미지와 텍스트를 모두 확인할 수 있음
- 점자로도 변환되어 표시됨

**완료 기준:**
- 스크립트 실행 시 완전한 학습 데이터셋 생성

### Phase 1: 기초 AI/ML 기능 (예상: 2-3개월)

**목표**: 기본적인 AI 기능으로 사용자 경험 개선

#### 1.1 강의 음성-텍스트 자동 동기화 ⭐⭐⭐⭐ (3-4주)

**왜 필요한가?**
- 사용자 피드백에서 가장 큰 불편사항
- 알림음 기반 수동 동기화를 자동화로 개선

**해야 할 일:**
- [ ] STT (Speech-to-Text) 통합
  - [ ] Google Speech-to-Text API 또는 Whisper 선택
  - [ ] 한국어 음성 인식 설정
- [ ] 음성-텍스트 매칭 알고리즘 구현
  - [ ] 문자열 유사도 기반 매칭
  - [ ] 키워드 기반 매칭
- [ ] 실시간 동기화 기능
  - [ ] 강의 재생 위치 감지
  - [ ] 해당 텍스트 섹션으로 자동 스크롤
  - [ ] 점자 디바이스 자동 업데이트
- [ ] 프론트엔드 통합
  - [ ] `useAudioSync` 훅 구현
  - [ ] UI에 동기화 상태 표시

**완료 기준:**
- 강의 재생 시 자동으로 해당 텍스트가 하이라이트됨
- 점자 디바이스에 해당 섹션이 자동 전송됨
- 동기화 정확도 90% 이상

**예상 효과:**
- 학습 효율성 30% 향상
- 사용자 만족도 대폭 증가

---

#### 1.2 학습자 맞춤형 추천 시스템 ⭐⭐⭐ (4주)

**왜 필요한가?**
- 소규모 사용자 (9명) 최적화
- 개인화된 학습 경험 제공

**해야 할 일:**
- [ ] 사용자 행동 데이터 수집 시스템
  - [ ] 학습 이력 로깅
  - [ ] 오답 패턴 추적
  - [ ] 학습 시간대 분석
- [ ] 추천 엔진 구현
  - [ ] 강의 순서 기반 추천 (00강→01강→...)
  - [ ] 오답 패턴 기반 복습 추천
  - [ ] 콘텐츠 기반 필터링
- [ ] API 엔드포인트 구현
  - [ ] `GET /api/v1/recommendations/next-lesson`
  - [ ] `GET /api/v1/recommendations/review`
- [ ] 프론트엔드 통합
  - [ ] "오늘 학습 이어하기" 화면에 추천 표시
  - [ ] 단원 목록에 추천 순서 표시

**완료 기준:**
- "오늘 학습 이어하기"에서 AI 추천 다음 강의 표시
- 틀린 문제 기반 복습 강의 자동 추천
- 추천 정확도 60% 이상 (사용자가 추천 콘텐츠를 학습하는 비율)

**예상 효과:**
- 학습 완료율 20% 증가
- 학습 효율성 향상

---

#### 1.3 점자 변환 ML 모델 개발 ⭐⭐⭐ (8-10주)

**왜 필요한가?**
- 규칙 기반 변환의 한계 극복
- 문맥을 이해하는 정확한 점자 변환

**해야 할 일:**
- [ ] 데이터셋 준비 (Phase 0.5 완료 후)
  - [ ] Train/Validation/Test 세트 분할
  - [ ] 데이터 증강
- [ ] 모델 아키텍처 설계
  - [ ] KoBERT/KoGPT 기반 Seq2Seq 모델
  - [ ] 점자 토크나이저 개발
- [ ] 모델 학습
  - [ ] 하이퍼파라미터 튜닝
  - [ ] 학습 및 검증
- [ ] 모델 서빙 인프라
  - [ ] 추론 API 구현
  - [ ] 기존 규칙 기반과 병행 (Fallback)
- [ ] 프론트엔드 통합
  - [ ] ML 모델 점자 변환 옵션 추가

**완료 기준:**
- BLEU Score 0.85 이상
- 정확도 95% 이상
- 추론 속도 100자당 1초 이내

**예상 효과:**
- 동음이의어 처리 개선
- 점자 변환 정확도 10% 이상 향상

### Phase 2: 고급 AI 기능 (예상: 2-3개월)

**목표**: 생성형 AI를 활용한 고급 기능

  - [ ] 문제 해설 생성
  - [ ] 핵심 포인트 요약
  - [ ] 개념 설명 보강
- [ ] 캐싱 전략 (비용 최적화)

## 💡 개발 시 주의사항

- **현재 타겟**: 예비고 학생 (학습 방법 탐색 단계)
- **고려사항**: 소규모 사용자 (9명) → 개인화 중심 접근
- **제작자 확대**: 자동화로 제작 시간 단축 → 더 많은 제작자 참여 유도

- AI 생성 콘텐츠는 명시적 표시 (사용자 신뢰)
- 점자 변환은 ML 모델과 규칙 기반 병행 (안전성)

### 3. 비용 관리
- LLM API 사용량 모니터링
- 캐싱 전략으로 비용 절감
- 오픈소스 LLM (Ollama) 옵션 고려

### 4. 접근성
- 모든 기능은 점자 디바이스 연동 필수
- 스크린 리더 지원
