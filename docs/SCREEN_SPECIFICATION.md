## 공통 레이아웃 구조

모든 화면은 `AppShellMobile` 컴포넌트를 사용하며, 다음 구조를 가집니다:

```
┌─────────────────────────────────────┐
│  [홈] [제목] [🔊]                    │  ← 상단 헤더 (고정)
├─────────────────────────────────────┤
│                                     │
│  🎤 [음성 인식 바]                   │  ← 음성 명령 표시줄 (선택적)
│                                     │
│  ┌───────────────────────────────┐ │
│  │  [카드 1]                     │ │
│  └───────────────────────────────┘ │
│                                     │
│  ┌───────────────────────────────┐ │
│  │  [카드 2]                     │ │  ← 메인 콘텐츠
│  └───────────────────────────────┘ │     (세로 스크롤)
│                                     │
│  ┌───────────────────────────────┐ │
│  │  [카드 3]                     │ │
│  └───────────────────────────────┘ │
│                                     │
├─────────────────────────────────────┤
│ [홈] [교재] [문항] [어휘] [시험]    │  ← 하단 탭 네비게이션 (고정)
└─────────────────────────────────────┘
```

### 공통 요소

1. **상단 헤더** (고정)
   - 왼쪽: 홈 버튼 (현재 페이지가 홈이 아닐 때만 표시)
   - 중앙: 화면 제목
   - 오른쪽: 음성 안내 ON/OFF 버튼 (🔊)

2. **음성 인식 바** (선택적)
   - 마이크 상태 표시
   - 음성 명령 전사본 표시
   - 대부분의 화면에 표시

3. **하단 탭 네비게이션** (고정)
   - 홈: 메인 화면 (`/`)
   - 교재: 교과서/지문 학습 (`/textbook`)
   - 문항: 문제 풀이 (`/question`)
   - 어휘: 어휘 학습 (`/vocab`)
   - 시험: 시험 모드 (`/exam-mode`)

### 모바일 앱 특성

- **화면 크기**: 모바일 세로 모드 (375px ~ 428px 너비)
- **최대 너비**: md 브레이크포인트 (약 768px)에서 중앙 정렬
- **디자인**: 카드 기반 세로 스크롤 구조
- **접근성**: 터치 친화적 (최소 44x44px), 음성 명령, 점자 디바이스 연동

### 1.3 주요 기능

1. **오늘 학습 이어하기** - 카드 형태
   - 현재 진행 중인 학습 정보 표시
   - 이어하기 버튼 클릭 시 학습 화면으로 이동
   - 음성 명령: "이어하기", "계속"

2. **과목 선택** - 카드 형태, 버튼 3개
   - 국어, 영어, 수학 선택 가능
   - 각 과목별 교과서 목록으로 이동
   - 음성 명령: "국어", "영어", "수학"

3. **교재 관리** - 카드 형태, PDF 목록
   - PDF 파일 업로드
   - 업로드된 PDF 목록 및 분석 상태 표시
   - 음성 명령: "교재 관리", "PDF 업로드"

4. **점자 디바이스 연결** - 카드 형태
   - BLE 점자 디바이스 연결/해제
   - 연결 상태 표시
   - 음성 명령: "점자 연결", "디바이스 연결"

### 1.4 음성 명령

| 명령어 | 동작 |
|--------|------|
| "이어하기", "계속" | 현재 학습 이어가기 |
| "국어" | 국어 과목 선택 |
| "영어" | 영어 과목 선택 |
| "수학" | 수학 과목 선택 |
| "교재 관리" | 교재 관리 화면으로 이동 |
| "점자 연결" | 점자 디바이스 연결 화면 |

### 2.3 주요 기능

1. **커리큘럼 기반 학습**
   - 자동 생성된 커리큘럼 기반 학습 경로 표시
   - 레슨 간 의존성 확인
   - 학습 순서 자동 결정
   - 이전/다음 레슨 네비게이션

2. **학습 단위 관리**
   - 강의대본 분석 기반 학습 단위 자동 분할
   - 섹션별 분류 (OT, 개념, 예제, 문제 등)
   - 학습 단위별 진행 상황 추적
   - 말하는 단위로 자동 분할

3. **청크 단위 읽기**
   - 텍스트를 "말하는 단위"로 분할
   - 각 청크를 TTS로 읽고 점자로 출력
   - 이전/다음 청크 이동
   - 섹션 간 이동

4. **점자 디바이스 연동**
   - BLE를 통한 실시간 점자 출력
   - 3-cell 패킷 단위 전송
   - 연결 상태 모니터링
   - 점자 패턴 미리보기

5. **TTS 재생 제어**
   - 재생/일시정지
   - 이전/다음 청크 이동
   - 반복 재생
   - 강의 음성 동기화 (알림음 기반)

6. **PDF 참조 정보**
   - 강의대본에서 추출한 PDF 참조 표시
   - 관련 문제 바로가기
   - PDF 원본 보기

7. **학습 진행 상황**
   - 레슨별 진행률 표시
   - 학습 단위별 완료 상태
   - 전체 커리큘럼 진행률

8. **그래프/표 처리**
   - 이미지가 있는 경우 미리보기 표시
   - 점자 패턴으로 변환 가능

### 2.4 화면 구성 요소

#### 2.4.1 학습 경로 표시 (모바일: 모달, 데스크톱: 왼쪽 패널)
- 전체 커리큘럼 구조
- 현재 레슨 하이라이트
- 완료된 레슨 표시 (✅)
- 진행 중인 레슨 표시 (⏳)
- 레슨 간 의존성 표시

#### 2.4.2 섹션 목록 (모바일: 모달, 데스크톱: 왼쪽 패널)
- 레슨 내 섹션 목록 (OT, 개념, 예제 등)
- 현재 섹션 하이라이트
- 섹션별 학습 단위 수
- 섹션 간 이동

#### 2.4.3 학습 단위 표시
- 현재 학습 단위 정보
- 점자 시각화
- 텍스트 표시
- TTS 재생 컨트롤
- 진행률 표시

#### 2.4.4 PDF 참조 정보
- 강의대본에서 추출한 PDF 참조
- 관련 문제 번호
- PDF 원본 보기 링크
- 문제 풀이 바로가기
