## 1️⃣ 설계 목표 (Design Goal)

본 설계의 목표는 다음과 같다.

> 문학 교재 PDF에서
> **'개념 설명 영역', '작품/본문 영역', '문제 영역'을
> 사람의 교재 독해 방식과 최대한 동일하게 자동 분리**하고,
> 이를 **이미지 크롭 + 텍스트(JSON)** 형태로 생성한다.

본 설계는:

* 모델 정확도 극대화 ❌
* **교재 구조 해석의 일관성 ⭕**
  을 최우선 목표로 한다.

---

## 2️⃣ 설계 철학 (변경 없음)

* OCR + 좌표 기반 규칙 중심 설계
* YOLO 등 객체 탐지 모델 사용 ❌
* "의미 단위" 우선, 좌표는 결과

---

## 3️⃣ 문학 교재의 실제 구조 정의 (보강)

문학 교재는 다음의 **3단 반복 구조**를 갖는다.

```
[개념 설명 영역]
 → [작품 / 본문 영역]
 → [문제 영역]
```

각 영역은 **시각적·의미적으로 명확히 분리**되어 있으며,
본 설계는 이 구조를 그대로 따른다.

---

## 4️⃣ 개념 영역 설계 정의 (v1.1 수정)

### 4.1 개념 영역의 시작 조건

개념 영역은 다음 중 하나를 만족할 때 시작된다.

* 번호 + 개념명
  * 예: `1 시적 표현`, `2 시의 형식`
* 짧은 명사형 제목 (≤ 30자)
* 페이지 상단부 위치
* 평균 텍스트 높이가 본문 대비 큼

---

### 4.2 개념 영역의 구성 요소 (※ v1.1 핵심 수정)

**개념 영역에는 다음 요소를 모두 포함한다.**

1. 중앙 개념 설명 본문
2. **좌측 보조 개념 설명 박스**
   * 초록 아이콘으로 시작
   * 핵심 요약 / 보충 설명 역할

📌 **좌측 보조 박스는 '부수 요소'가 아니라
개념 이해에 필수적인 구성 요소로 간주한다.**

→ 따라서 **개념 영역 bbox에 반드시 포함**한다.

---

### 4.3 개념 영역의 종료 조건

개념 영역은 다음 중 하나에서 종료된다.

1. 다음 개념 제목 등장
2. `작품으로 이해하기` 헤더 등장
3. 문제 번호 패턴 등장 (`01`, `02` 등)
4. 페이지 종료

---

### 4.4 개념 영역 bbox 계산 기준

* `top`: 개념 제목 줄의 top
* `bottom`: 종료 조건 직전
* `left`: 좌측 보조 박스의 left 포함
* `right`: 개념 본문 최대 right

👉 **좌/우 컬럼 전체를 하나의 개념 블록으로 간주한다.**

---

## 5️⃣ 작품 / 본문 영역 설계 정의 (변경 없음)

### 5.1 시작 조건

* `작품으로 이해하기` 헤더 등장
* 짧은 명사형 제목
* 개념 영역 종료 직후

---

### 5.2 종료 조건

1. 문제 번호 등장
2. 다음 본문 헤더
3. 페이지 종료

---

### 5.3 bbox 계산 기준

* `top`: 본문 헤더 top
* `bottom`: 문제 번호 직전
* `left/right`: 해당 영역 내 모든 텍스트 포함

📌 **시 전문은 하나의 연속 본문으로 처리한다.**

---

## 6️⃣ 문제 영역 설계 정의 (v1.1 보강)

### 6.1 문제 영역의 시작 조건

* 문제 번호 패턴 등장
  * 예: `01`, `02`
* 번호가 독립된 줄로 존재

---

### 6.2 문제 영역의 캡처 단위 (※ v1.1 핵심 수정)

**문제 영역은 다음을 하나의 블록으로 캡처한다.**

* 문제 번호
* 문제 지문
* 선택지 전체 (①②③④⑤)

📌 **문제 내부 구조 분해는 이미지 단계에서 수행하지 않는다.**

---

### 6.3 문제 영역의 세부 구조 처리 위치

* 이미지 크롭 단계: ❌ 세분화 안 함
* **JSON 생성 단계: ⭕ 세분화 수행**

JSON에서 다음을 분리한다:

* `question_text`
* `choices[]`
* `question_number`

## 8️⃣ 설계-구현 일치 선언 (v1.1 핵심)

> 본 설계 문서 v1.1은
> **실제 교재 캡처 결과를 기준으로 수정되었으며**,
> 현재 구현된 캡처 결과와 **논리적·시각적으로 일치한다.**

이는 설계 오류가 아니라
**설계 → 구현 → 피드백 → 설계 보정의 정상적인 반복 과정**이다.

---

## 9️⃣ 설계 책임 명시

* 개념 / 본문 / 문제의 정의 기준: **설계자**
* 좌표 계산 및 자동화 로직: **구현**
* AI 설명 및 TTS: **후처리**

---

## ✅ 최종 평가 (냉정하게)

* ❌ 설계 문서가 현실과 어긋남 → 아님
* ❌ 캡처 결과가 임시방편 → 아님
* ⭕ **설계가 실제 결과를 흡수한 '성숙 단계'**

이 문서 상태면:

* 졸업작품 제출 ✔️
* 발표에서 "왜 이렇게 잘랐는가" 질문 ✔️
* 포트폴리오 설계 설명 ✔️
