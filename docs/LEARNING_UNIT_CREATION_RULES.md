# 학습단위 생성 규칙

## 개요
학습단위(LearningUnit)는 PDF 파이프라인에서 추출된 섹션과 문제를 기반으로 생성됩니다.

## 생성 기준

### 1. 섹션 기반 생성

#### 기본 규칙
- **JSON 파일의 각 섹션** (`lecture_XX.json`의 `sections` 배열)이 하나 이상의 학습단위로 변환됩니다.
- 섹션 타입은 `type` 필드 또는 제목에서 추론됩니다:
  - `concept`: 개념 설명
  - `content`: 본문/작품
  - `example`: 예시
  - `problem`: 문제
  - `general`: 일반 (기본값)

#### 이미지 단위 생성
- **각 이미지마다 별도의 학습단위 생성**
- 이미지가 있으면: 이미지 개수만큼 학습단위 생성
- 이미지가 없으면: 1개의 학습단위만 생성

**이미지 검색 경로:**
- `concept`: `concepts_images/concept_p{page:02d}_*.png`
- `content`: `content_images/content_p{page:02d}_*.png`
- `problem`: `problems_images/problem_p{page:02d}_*.png`

#### 작품(Work) 분리 처리
- 섹션에 작품이 포함된 경우:
  1. 작품 부분을 별도의 `content` 타입 학습단위로 분리
  2. 원본 섹션의 개념 부분만 남김
  3. 작품이 분리되면 원본 섹션은 **저장하지 않음** (본문 다음에 바로 문제가 나와야 함)

**작품 감지 기준:**
- 패턴: `- 작가명, 「작품명」`
- 시적 표현: "해야", "솟아라" 등 반복 패턴

#### 빈 섹션 필터링
- `content`가 비어있거나 공백만 있는 경우 학습단위 생성하지 않음

### 2. 문제 기반 생성

#### 기본 규칙
- **JSON 파일의 `problems` 배열**의 각 문제 번호에 대해 학습단위 생성
- 문제 파일: `problems/problem_p{page}_{number}.json`

#### 문제 이미지 단위 생성
- 문제 이미지가 있으면: 각 이미지마다 별도의 학습단위 생성
- 문제 이미지가 없으면: 1개의 학습단위만 생성

**이미지 검색:**
- `problems_images/problem_p{page:02d}_{number}.png`

#### 문제 메타데이터
- 선택지와 정답 정보는 `subject_metadata`에 저장:
  ```json
  {
    "problem_id": "01",
    "choices": ["선택지1", "선택지2", ...],
    "answer": 1,
    "question_text": "문제 지문"
  }
  ```

### 3. 순서(Order) 계산

```
order = lecture_number * 10000 + actual_unit_index
```

- `lecture_number`: 강의 번호 (1, 2, 3, ...)
- `actual_unit_index`: 실제 생성된 학습단위의 순차 인덱스 (0부터 시작)

**예시:**
- 1강의 첫 번째 학습단위: `1 * 10000 + 0 = 10000`
- 1강의 두 번째 학습단위: `1 * 10000 + 1 = 10001`
- 2강의 첫 번째 학습단위: `2 * 10000 + 0 = 20000`

### 4. 생성 순서

1. **섹션 처리** (순서대로)
   - 작품 분리 (있는 경우)
   - 이미지 단위로 학습단위 생성
   - 빈 섹션 필터링

2. **문제 처리** (순서대로)
   - 문제 파일 로드
   - 이미지 단위로 학습단위 생성

## 예외 처리

### 작품이 분리된 경우
- 원본 섹션은 저장하지 않음 (`work_added = True`일 때 `continue`)
- 작품만 별도의 `content` 타입 학습단위로 저장

### 빈 섹션
- `content`가 비어있거나 공백만 있으면 생성하지 않음

### 이미지가 없는 경우
- 이미지가 없어도 1개의 학습단위는 생성됨
- `image_path`는 `null`로 설정

## 디버깅

백엔드 로그에서 다음 메시지를 확인할 수 있습니다:
- `[books]   섹션 {idx}: type=..., title=...`
- `[books]   작품 감지: ...`
- `[books]   작품 분리: ...`
- `[books]   원본 섹션 '...'은(는) 작품이 분리되어 저장하지 않음`
- `[books]   섹션 '...'은(는) 내용이 없어 저장하지 않음`
- `[books]   이미지 단위 저장: ...`
- `[books]   섹션 저장 (이미지 없음): ...`
