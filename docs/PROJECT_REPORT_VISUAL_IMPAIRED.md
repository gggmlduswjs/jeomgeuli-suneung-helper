# 점그리 수능 도우미 프로젝트 보고서

## (제안)

시각장애 수험생은 일반 수험생 대비 4~6개월 늦게 교재를 받아 학습을 시작한다. EBS 점자 교재가 9~10월에야 완성되어 배포되는 경우가 빈번하며, 이는 학습 계획 수립, 반복 학습, 심화 학습 전반에 걸친 구조적 불리함으로 이어진다.

초기 문제 인식 단계에서는 이러한 시기적 지연이 단순히 교재 배포 일정의 문제일 뿐이라고 생각했다. 그러나 실제 수능 시험 환경을 조사해보니 문제의 본질이 더 깊다는 것을 알게 되었다. 시각장애 수험생은 점역된 시험지를 사용하며, 일반 수험생 대비 2배 이상의 시험 시간(8~12시간)이 소요된다. 점자 읽기와 음성 정보 처리를 동시에 수행해야 하는 높은 인지 부하, 특히 수학과 국어 과목에서의 어려움이 누적되어 학습 효과를 저해하고 있었다.

더욱이 학습 자료 접근성 측면에서도 근본적인 한계가 있었다. 교재 점역 시기가 3월이 아닌 9월 이후로 지연되는 것은 단순한 일정 문제가 아니라, 단순 텍스트 변환만 제공되어 구조화된 학습 자료가 부족하고, 질문에 대한 즉각적인 피드백을 받기 어려운 구조적 문제의 결과였다. 기존 점역 시스템은 PDF를 단순히 텍스트로 변환하는 수준에 그쳐, 개념-본문-문제로 체계화된 학습 흐름을 제공하지 못했다.

이에 단순히 점역 시기를 앞당기는 것만으로는 해결할 수 없다는 문제의식에 도달했다. 시각장애 수험생이 타인의 도움 없이 일반 수험생과 동일한 시점에 학습을 시작할 수 있으려면, 교재 자동 파싱부터 점자 디스플레이 연동, AI 기반 학습 도우미, 음성 인터페이스까지 포괄하는 완결된 학습 시스템이 필요하다는 결론에 이르렀다.

## (기획)

시각장애 수험생이 독립적으로 학습할 수 있는 완결된 학습 시스템을 구축하는 것을 목표로 설정했다. 이를 위해 핵심 기획 방향을 접근성 중심, 콘텐츠 자동화, 학습 효율 개선, 독립 학습 보장의 4가지 축으로 정립했다.

먼저 접근성 중심 설계를 위해 점자·음성 기반 인터페이스를 핵심으로 두었다. 실제 수능 시험 환경과 유사한 학습 환경을 제공하기 위해 아두이노 기반 3셀 점자 디스플레이 하드웨어를 직접 개발하고 BLE 연동을 구현했으며, Web Speech API 기반 STT/TTS 기능을 필수 요소로 정의했다. 특히 한글점자규정을 준수한 점자 변환 시스템을 구축하여 실제 시험 환경과의 일치성을 확보했다.

콘텐츠 자동화 측면에서는 PDF 자동 파싱 시스템을 핵심으로 설계했다. 기존에는 PDF를 수동으로 점역하는 데 수 시간이 소요되었으나, AI 기반 구조 분석과 템플릿 시스템을 통해 수 분으로 변환 시간을 90% 단축하는 것을 목표로 했다. 템플릿 기반 파싱 시스템을 통해 교재 유형별로 재사용 가능한 파싱 로직을 구축하여, 새로운 교재 추가 시에도 빠르게 대응할 수 있도록 설계했다.

학습 효율 개선을 위해 AI 기반 설명·해설 시스템과 과목별 학습 흐름 구성을 계획했다. GPT-4o-mini를 활용한 질의응답 시스템과 RAG(Retrieval-Augmented Generation) 기반 유사 콘텐츠 추천 시스템을 통해 즉각적인 피드백을 제공하고, 개념-본문-문제 순차 학습 구조로 체계적인 학습 경험을 설계했다.

독립 학습 보장을 위해 실제 수능 환경을 반영한 기능들을 포함했다. 텍스트 찾기(Ctrl+F) 기능, 수식 계산 도구, 특수문자 변형 처리(예: (가) ↔ ㈎) 등을 구현하여 시험 환경과 동일한 조건에서 학습할 수 있도록 기획했다.

## (설계)

시스템 구조는 Frontend와 Backend로 명확히 분리하여 설계했다. Frontend는 React + TypeScript 기반 PWA로 구현하여 오프라인 사용도 가능하도록 했고, Web Bluetooth API와 Web Speech API를 활용하여 점자 디스플레이 연동과 음성 인터페이스를 구현했다. 아두이노 기반 3셀 점자 디스플레이 하드웨어는 직접 개발하여 한글점자 변환 로직과 BLE 통신을 구현했고, Backend는 FastAPI 기반 비동기 처리 구조로 설계하여 대용량 PDF 파싱 작업도 효율적으로 처리할 수 있도록 했다.

파이프라인 설계에서는 PDF → 텍스트 추출 → 구조화 파싱 → JSON 저장의 단계적 프로세스를 구축했다. 하이브리드 전략을 채택하여 규칙 기반 파싱과 AI 기반 파싱을 조합함으로써, 다양한 교재 형식에 대응하면서도 정확도를 확보했다. 템플릿 기반 파싱 시스템을 통해 교재 유형별로 재사용 가능한 파싱 로직을 저장하고, 새로운 교재 추가 시 템플릿을 선택하거나 AI 기반으로 자동 생성할 수 있도록 설계했다.

AI/ML 통합 측면에서는 LLM(GPT-4o)과 RAG 시스템(Sentence-Transformers + FAISS)을 결합했다. 질의응답 시스템은 GPT-4o-mini를 활용하여 학습 내용에 대한 즉각적인 답변을 제공하고, RAG 시스템은 벡터 데이터베이스를 통해 유사한 학습 콘텐츠를 추천하여 학습의 연속성을 확보했다.

데이터베이스 설계에서는 교재, 강의, 단원, 개념, 본문, 문제의 계층적 구조를 반영하여, 학습 흐름에 맞는 데이터 접근이 가능하도록 했다. 진도 추적 시스템을 통해 사용자의 학습 상태를 저장하고, 학습 요약 페이지에서 진행 상황을 한눈에 확인할 수 있도록 설계했다.

접근성 우선 설계 원칙에 따라 점자 디스플레이, 음성 인터페이스, 키보드 단축키를 모두 지원하도록 구현했다. 특히 점자 변환은 한글점자규정을 엄격히 준수하여 실제 시험 환경과의 일치성을 확보했고, 음성 명령을 통해 화면 전환, 학습 진행 등 주요 기능을 제어할 수 있도록 설계했다.

## (결과)

핵심 기능 구현을 완료하여 시각장애 수험생이 독립적으로 학습할 수 있는 완결된 시스템을 구축했다.

PDF 자동 파싱 시스템을 통해 기존 수 시간 소요되던 점역 작업을 수 분으로 단축했으며, 템플릿 기반 파싱과 AI 구조 분석으로 강의 목록을 자동 추출한다. 점자 변환 및 연동 시스템은 아두이노 기반 3셀 점자 디스플레이 하드웨어를 직접 개발하여 한글점자규정을 준수한 변환 로직과 BLE 통신을 구현했고, AI 학습 도우미는 GPT-4o-mini 기반 질의응답과 RAG 기반 유사 콘텐츠 추천을 통해 즉각적인 피드백을 제공한다. 음성 인터페이스는 Web Speech API 기반 STT/TTS로 음성 명령 제어를 지원하며, 학습 관리 시스템은 개념-본문-문제 순차 학습 구조와 진도 추적을 구현했다. 관리자 기능으로 AI 기반 템플릿 생성과 PDF 업로드/파싱 자동화를 제공하고, 수능 환경 반영 기능으로 텍스트 찾기, 수식 계산 도구, 특수문자 변형 처리를 구현했다.

이후 시스템 테스트와 사용자 피드백을 반영하여 지속적으로 개선했으며, 실제 시각장애 수험생이 사용할 수 있는 수준의 완성도를 확보했다. 그 결과 본 프로젝트는 단순한 점역 도구를 넘어, 시각장애 수험생이 독립적으로 학습할 수 있는 완결된 학습 플랫폼으로 완성되었다.
