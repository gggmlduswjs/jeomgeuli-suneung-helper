## 1. 개요

### 1.1 목적
시각장애 수험생을 위한 접근 가능한 학습 플랫폼의 UI/UX 설계 명세

### 1.2 디자인 원칙
- **접근성 우선**: WCAG 2.1 AA 수준 준수
- **직관적 네비게이션**: 음성 명령 및 키보드 단축키 지원
- **반응형 디자인**: 다양한 화면 크기 지원
- **일관성**: 일관된 디자인 시스템 적용

### 1.3 디자인 시스템
- **컬러**: Tailwind CSS 기본 컬러 팔레트
- **타이포그래피**: 시스템 폰트 (접근성 고려)
- **간격**: 4px 기준 그리드 시스템
- **아이콘**: Lucide React 아이콘 라이브러리

## 3. 주요 화면 상세

### 3.1 SC-01: 시작 화면 (`/`)

#### 화면 개요
앱 진입점으로, 사용자에게 환영 메시지와 주요 기능 안내를 제공

#### 레이아웃
```
┌─────────────────────────────────────┐
│                                     │
│         [로고 또는 타이틀]           │
│                                     │
│      점그리 수능 도우미              │
│                                     │
│    [시작하기 버튼]                  │
│                                     │
│    주요 기능 안내                    │
│    - PDF 자동 파싱                  │
│    - 점자 디스플레이 연동            │
│    - AI 학습 도우미                  │
│                                     │
└─────────────────────────────────────┘
```

#### 주요 요소
- **타이틀**: "점그리 수능 도우미"
- **시작하기 버튼**: `/books`로 이동
- **주요 기능 안내**: 3-4개 핵심 기능 요약

#### 접근성
- 키보드로 모든 요소 접근 가능
- 스크린 리더 지원
- 음성 명령: "시작하기" 또는 "교재 선택"

---

### 3.2 SC-02: 교재 선택 (`/books`)

#### 화면 개요
사용 가능한 교재 목록을 표시하고 선택할 수 있는 화면

#### 레이아웃
```
┌─────────────────────────────────────┐
│  [뒤로가기]  교재 선택              │
├─────────────────────────────────────┤
│  [과목 필터]                        │
│  [전체] [문학] [영어] [수학1]       │
├─────────────────────────────────────┤
│                                     │
│  ┌──────────┐  ┌──────────┐        │
│  │ 교재 카드 │  │ 교재 카드 │        │
│  │          │  │          │        │
│  └──────────┘  └──────────┘        │
│                                     │
│  ┌──────────┐  ┌──────────┐        │
│  │ 교재 카드 │  │ 교재 카드 │        │
│  │          │  │          │        │
│  └──────────┘  └──────────┘        │
│                                     │
└─────────────────────────────────────┘
```

#### 교재 카드 구성
- **제목**: 교재명
- **과목**: 문학, 영어, 수학1
- **연도**: 2026
- **상태**: 파싱 완료 여부
- **선택 버튼**: 클릭 시 강의 목록으로 이동

#### 주요 기능
- 과목별 필터링
- 검색 기능 (선택적)
- 교재별 파싱 상태 표시

#### 접근성
- 키보드 네비게이션 (Tab, Enter)
- 스크린 리더: "교재 목록, 총 N개"
- 음성 명령: "문학 교재 선택"

│  │ 페이지: 9-15                 │  │

│  └──────────────────────────────┘  │

- **진도 표시**: 학습 완료 여부 (선택적)

#### 주요 기능
- 강의 목록 스크롤
- 강의 선택 및 학습 시작
- 학습 진도 표시

### 3.4 SC-04: 단원 학습 (`/unit/:unitId`)

#### 화면 개요
카드 스와이프 기반으로 단원을 학습하는 화면

#### 레이아웃
```
┌─────────────────────────────────────┐
│  [뒤로가기]  {강의명}               │
├─────────────────────────────────────┤
│                                     │
│  ┌──────────────────────────────┐  │
│  │                              │  │
│  │      단원 카드                │  │
│  │                              │  │
│  │  [개념/본문/문제]             │  │
│  │                              │  │
│  │  내용...                     │  │
│  │                              │  │
│  └──────────────────────────────┘  │
│                                     │
│  [이전]  [다음]  [AI 질문]         │
│                                     │
│  [점자 출력]  [음성 읽기]          │
└─────────────────────────────────────┘
```

#### 단원 카드 구성
- **타입 표시**: 개념, 본문, 문제
- **내용**: 텍스트 및 이미지
- **페이지 번호**: 현재 페이지 표시
- **이미지**: 개념/문제 이미지 (있는 경우)

#### 주요 기능
- 카드 스와이프로 다음/이전 단원 이동
- 점자 디스플레이 출력
- 음성 읽기 (TTS)
- AI 질의응답

#### 접근성
- 키보드 단축키:
  - `←` / `→`: 이전/다음 단원
  - `Space`: 음성 읽기
  - `Q`: AI 질문
- 스크린 리더: 단원 타입 및 내용 읽기
- 음성 명령: "다음", "이전", "질문하기"

## 4. UI/UX 가이드라인

### 4.1 컬러 시스템

#### 주요 컬러
- **Primary**: 파란색 계열 (기본 액션)
- **Secondary**: 회색 계열 (보조 액션)
- **Success**: 초록색 계열 (성공 상태)
- **Error**: 빨간색 계열 (에러 상태)
- **Warning**: 노란색 계열 (경고)

#### 텍스트 컬러
- **Primary Text**: 진한 회색 (#1e1e1e)
- **Secondary Text**: 중간 회색 (#666666)
- **Muted Text**: 연한 회색 (#999999)

### 4.2 타이포그래피

#### 폰트 크기
- **H1**: 2rem (32px) - 페이지 타이틀
- **H2**: 1.5rem (24px) - 섹션 타이틀
- **H3**: 1.25rem (20px) - 서브 섹션
- **Body**: 1rem (16px) - 본문
- **Small**: 0.875rem (14px) - 보조 텍스트

#### 폰트 패밀리
- 시스템 폰트 사용 (접근성 고려)
- `-apple-system, BlinkMacSystemFont, "Segoe UI", Roboto, sans-serif`

### 4.3 간격 시스템

#### 기준 간격
- **xs**: 4px
- **sm**: 8px
- **md**: 16px
- **lg**: 24px
- **xl**: 32px
- **2xl**: 48px

### 4.4 컴포넌트 스타일

#### 버튼
- **Primary Button**: 파란색 배경, 흰색 텍스트
- **Secondary Button**: 회색 배경, 검은색 텍스트
- **Ghost Button**: 투명 배경, 파란색 텍스트

#### 카드
- 흰색 배경
- 그림자 효과 (shadow)
- 둥근 모서리 (border-radius: 8px)
- 패딩: 16px

#### 입력 필드
- 테두리: 1px solid #ddd
- 포커스: 파란색 테두리
- 패딩: 12px
- 둥근 모서리: 4px

## 5. 접근성 요구사항

### 5.1 키보드 네비게이션

#### 기본 단축키
- **Tab**: 다음 요소로 이동
- **Shift + Tab**: 이전 요소로 이동
- **Enter / Space**: 버튼 클릭
- **Esc**: 모달 닫기

#### 화면별 단축키
- **단원 학습 화면**:
  - `←`: 이전 단원
  - `→`: 다음 단원
  - `Space`: 음성 읽기
  - `Q`: AI 질문
  - `B`: 점자 출력

### 5.2 스크린 리더 지원

#### ARIA 레이블
- 모든 버튼에 `aria-label` 제공
- 폼 입력에 `aria-describedby` 제공
- 상태 변경 시 `aria-live` 영역에 알림

#### 시맨틱 HTML
- `<header>`, `<main>`, `<nav>`, `<footer>` 사용
- `<button>`, `<a>` 등 적절한 요소 사용
- 제목 계층 구조 (`<h1>` ~ `<h6>`) 준수

### 5.3 음성 명령

#### 지원 명령어
- "시작하기" / "교재 선택"
- "다음" / "이전"
- "질문하기" / "AI 질문"
- "음성 읽기" / "읽어줘"
- "점자 출력" / "점자로"

### 5.4 점자 디스플레이 연동

#### 표시 정보
- 현재 단원 내용
- 네비게이션 상태
- 에러 메시지

#### 제어 방법
- 점자 디스플레이 버튼으로 네비게이션 (하드웨어 지원 시)
- 웹 인터페이스로 제어

## 6. 반응형 디자인

### 6.1 브레이크포인트

- **Mobile**: < 640px
- **Tablet**: 640px ~ 1024px
- **Desktop**: > 1024px

### 6.2 모바일 최적화

- 터치 친화적 버튼 크기 (최소 44x44px)
- 스와이프 제스처 지원
- 간결한 레이아웃

### 6.3 태블릿 최적화

- 2열 그리드 레이아웃
- 카드 기반 UI
- 향상된 가독성

### 6.4 데스크톱 최적화

- 3-4열 그리드 레이아웃
- 사이드바 네비게이션 (선택적)
- 키보드 단축키 강화
