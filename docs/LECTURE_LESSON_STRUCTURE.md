# 강의 대본 레슨 단위 구조화

## 🎯 목적

긴 강의 대본을 학습 가능한 레슨 단위로 나누어 구조화

---

## 📋 레슨 구조 예시 (2026 수능특강 문학 1강)

### 레슨 1: 강의 오리엔테이션 & 수특 활용 전략
- **내용**: 강의 목적, 수능특강 위상, 연계 구조
- **핵심**: 수특은 문제집이 아니라 수능 범위 지도
- **예상 시간**: 5분

### 레슨 2: 1강 핵심 개념 구조 안내
- **내용**: 시의 표현/형식/내용, 수능 출제 방식
- **핵심**: 문학 문제는 항상 세 축 중 하나를 건드린다
- **예상 시간**: 3분

### 레슨 3: 시의 표현 개념 정리 - 형상화
- **내용**: 형상화 개념, 표현 기법
- **핵심**: 표현 기법은 목적이 아니라 수단
- **예상 시간**: 4분

### 레슨 4: 시의 형식 개념 정리
- **내용**: 연·행·갈래, 형식과 내용의 관계
- **핵심**: 형식은 주제를 가장 잘 전달하기 위한 결과
- **예상 시간**: 3분

### 레슨 5: 어조 개념 집중 정리 (중요)
- **내용**: 독백체/대화체 구분, 청자 설정
- **핵심**: 대화체 ≠ 반드시 주고받는 대화
- **예상 시간**: 5분

### 레슨 6: 시의 내용 접근법 - 화자·정서
- **내용**: 화자 정서 찾기, "무엇을 어떻게" 공식
- **핵심**: 정서를 찾으면 주제는 자동으로 보인다
- **예상 시간**: 4분

### 레슨 7: 시어의 함축적 의미 읽기
- **내용**: 사전적 의미 → 맥락 확장
- **핵심**: 시어는 항상 한 단계 더 깊다
- **예상 시간**: 4분

### 레슨 8: 이미지·심상 정리
- **내용**: 감각 기관, 이미지 대립
- **핵심**: 이미지는 정서를 눈앞에 보이게 한다
- **예상 시간**: 3분

### 레슨 9: 작품 분석 ① 박두진 〈해〉 - 전체 분석
- **내용**: 제목, 상징, 반복·변주, 이미지 대립, 주제
- **핵심**: 이 작품 하나로 시 분석 공식 완성
- **예상 시간**: 8분
- **작품 분석 포함**: ✅

### 레슨 10: 〈해〉 기출 문제 풀이 & 선지 해석
- **내용**: 반복과 변주, 음성상징어, 활유법·의인법
- **핵심**: 선지는 표현 + 태도를 동시에 묻는다
- **예상 시간**: 6분
- **문제 풀이 포함**: ✅

### 레슨 11: 시조 감상 전략 안내
- **내용**: 시조 감상의 핵심 (종장), 접근법
- **핵심**: 시조도 결국 화자·정서
- **예상 시간**: 3분

### 레슨 12: 시조 작품 분석 ① 매화 시조
- **내용**: 표면 의미, 시어의 중의성, 창작 맥락
- **핵심**: 시어의 중의적 의미 이해
- **예상 시간**: 5분
- **작품 분석 포함**: ✅

### 레슨 13: 시조 작품 분석 ② 이원익 시조
- **내용**: 자연 현상 → 인간 이치 (유추), 설의법, 체념
- **핵심**: 유추에 의한 시상 전개
- **예상 시간**: 5분
- **작품 분석 포함**: ✅

### 레슨 14: 시조 작품 분석 ③ 사설시조 (사랑 예찬)
- **내용**: 추상적 대상의 구체적 형상화, 비유·과장
- **핵심**: 추상 → 구체 형상화
- **예상 시간**: 5분
- **작품 분석 포함**: ✅

### 레슨 15: 시조 통합 문제 풀이
- **내용**: 공통점/차이점 비교, 표현·태도 중심 선지
- **핵심**: 비교 문제는 공통점과 차이점을 명확히
- **예상 시간**: 6분
- **문제 풀이 포함**: ✅

### 레슨 16: 한 판에 담판 정리 & 마무리
- **내용**: 작품별 핵심 요약, 표현 형식 정리
- **핵심**: 복습용 정리
- **예상 시간**: 4분

## 🔧 구현 구조

### 1. 데이터 모델

```python
# api/app/db/models.py
class Lesson(Base):
    lesson_id: str
    book_id: str
    index: int  # 레슨 번호 (1, 2, 3, ...)
    title: str
    lecture_script_text: str  # 해당 레슨의 강의 대본
    estimated_time: int  # 예상 소요 시간 (분)
    key_points: str  # JSON: ["핵심1", "핵심2"]
    has_question: bool  # 문제 풀이 포함 여부
    has_analysis: bool  # 작품 분석 포함 여부
    created_at: datetime
```

## 💡 사용 시나리오

### 시나리오 1: 레슨 제목 기반 분할

```
[관리자]
1. 강의 대본 HWP 업로드
2. 레슨 제목 리스트 제공:
   [
     "강의 오리엔테이션",
     "핵심 개념 안내",
     "작품 분석 ①",
     ...
   ]
3. 자동으로 레슨 단위로 분할
4. DB 저장
```

### 시나리오 2: 자동 분할

```
[관리자]
1. 강의 대본 HWP 업로드
2. 자동으로 구분점 찾기:
   - "레슨 1", "레슨 2" 패턴
   - "이제 넘어가", "다음 보자" 패턴
   - "작품 분석" 키워드
   - "문제 풀이" 키워드
3. 레슨 단위로 분할
4. DB 저장
```

### 시나리오 3: 사용자 학습

```
[사용자]
1. 레슨 선택 (예: "1강")
2. 하위 레슨 목록 표시:
   - 레슨 1: 강의 오리엔테이션 (5분)
   - 레슨 2: 핵심 개념 안내 (3분)
   - ...
3. 레슨 선택 → AI 수업 시작
4. 강의 대본 기반 AI 설명
5. TTS 재생 + 점자 출력
```

## 🎯 장점

1. **학습 단위 명확화**: 긴 강의를 작은 단위로 나눔
2. **진행 상황 추적**: 각 레슨별 완료 여부 추적 가능
3. **AI 수업 최적화**: 레슨별 강의 대본으로 정확한 컨텍스트
4. **TTS/점자 출력**: 레슨 단위로 자연스러운 출력
5. **문제 풀이 연동**: 문제가 있는 레슨만 별도 처리

## 📊 레슨 메타데이터

각 레슨은 다음 정보를 포함:

- **기본 정보**:
  - 레슨 번호
  - 제목
  - 내용 (강의 대본 텍스트)
  
- **학습 정보**:
  - 예상 소요 시간
  - 핵심 포인트 리스트
  - 문제 풀이 포함 여부
  - 작품 분석 포함 여부
  
- **위치 정보**:
  - 원본 강의 대본에서의 시작/끝 위치
  - 이전/다음 레슨 연결
