# Step 2: 리팩토링 계획

## Phase 1: 섹션 추출 개선 (우선순위 높음)

### 목표
섹션 추출 정확도를 70% → 89%+로 향상

### 작업

#### 1.1 다중 전략 섹션 추출기 구현
**파일**: `backend/app/infrastructure/pdf/parsers/section_extractor.py` (신규)

**전략:**
1. **패턴 매칭** (빠름, 정확도 70-80%)
   - 기존 하드코딩된 정규식
   - config.json의 패턴
   - 신뢰도: 0.7-0.8

2. **AI 분석** (느림, 정확도 85-95%)
   - LLM을 사용하여 섹션 구조 분석
   - OCR 텍스트 샘플 분석
   - 신뢰도: 0.85-0.95

3. **휴리스틱 폴백** (안정성, 정확도 50-70%)
   - 레이아웃 기반 추론
   - 폰트 크기/위치 분석
   - 신뢰도: 0.5-0.7

**구현:**
- `ImprovedSectionExtractor` 클래스
- 전략 패턴 적용
- 신뢰도 기반 선택
- 결과 병합 및 검증

**예상 시간**: 4-6시간

#### 1.2 OCR 전처리 강화
**파일**: `backend/app/infrastructure/pdf/parsers/text_preprocessor.py` (신규)

**개선 사항:**
- 공백 정규화
- 특수 문자 정리
- 폰트 인코딩 문제 해결
- 텍스트 품질 점수 계산

**예상 시간**: 2-3시간

#### 1.3 에러 복구 메커니즘
**파일**: `backend/app/infrastructure/pdf/parsers/section_extractor.py`

**개선 사항:**
- 단계별 폴백
- 부분 성공 허용
- 상세한 에러 로깅
- 디버깅 정보 제공

**예상 시간**: 2-3시간

**총 예상 시간**: 8-12시간

## 예상 효과

### 섹션 추출 정확도
- **Before**: 70% (패턴 매칭만)
- **After**: 89%+ (다중 전략)

### 처리 속도
- **패턴 매칭**: 1-3초 (변화 없음)

- **휴리스틱**: 1-2초 (변화 없음)

### 안정성
- **Before**: 패턴 실패 시 빈 배열
- **After**: 최소한 휴리스틱으로 섹션 추출
