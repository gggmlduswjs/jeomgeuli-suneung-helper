## 1. 전체 시스템 아키텍처 개요

```mermaid
graph TB
    subgraph UI["사용자 인터페이스 레이어<br/>(Frontend - React + TypeScript)"]
    end
    
    subgraph API["API 게이트웨이 레이어<br/>(Backend - FastAPI Routers)"]
        BR[Books Router]
        LR[Literature Router]
        ER[English Router]
        MR[Math1 Router]
        AR[AI Router]
        BRR[Braille Router]
        TR[Templates Router]
        CR[Curriculum Router]
        LER[Lessons Router]
        UR[Units Router]
        PR[Progress Router]
        ANR[Answers Router]
    end
    
    subgraph Services["비즈니스 로직 레이어<br/>(Backend - Services)"]
        BS[Book Service<br/>- PDF 업로드 처리<br/>- 파싱 파이프라인 실행<br/>- 백그라운드 작업 관리]
        CS[Curriculum Service<br/>- 커리큘럼 생성<br/>- 파싱 결과 → 커리큘럼 변환]
        TS[Template Service<br/>- 템플릿 생성/수정/삭제<br/>- AI 기반 템플릿 자동 생성]
        BCS[Book Conversion Service<br/>- LearningUnit → Unit 변환]
        KBS[Korean Braille Service<br/>- 한글 텍스트 → 점자 변환<br/>- 표준 한글점자규정 준수]
        PTS[Progress Tracker Service<br/>- 학습 진도 추적<br/>- 이어서 학습하기]
    end
    
    subgraph Infra["인프라스트럭처 레이어<br/>(Backend - Infrastructure Components)"]
        subgraph PDF["PDF Processing Infrastructure"]
            UP[Unified Pipeline<br/>- PDF 추출<br/>- 텍스트 파싱<br/>- 강의 콘텐츠 추출<br/>- 결과 저장]
            HR[Hybrid Router Parser<br/>- Template 기반 파싱<br/>- AI 기반 파싱<br/>- Rule 기반 파싱]
            EXT[Extractors<br/>- PdfplumberExtractor<br/>- OCRExtractor<br/>- PyMuPDFExtractor]
            IMG[Image Processing<br/>- ImageSaver<br/>- ImageCache]
        end
        
        subgraph AIInfra["AI Infrastructure"]
            GEN[Generative AI genai/<br/>- StructureAnalyzer<br/>- StructureParser<br/>- ExplanationGenerator<br/>- MetadataEnricher<br/>- RAGRecommender]
            DL[Deep Learning dl/<br/>- LayoutAnalyzer<br/>- MathRecognizer]
        end
        
        DB[Database Infrastructure<br/>- SQLAlchemy ORM<br/>- SQLite/PostgreSQL<br/>- Session 관리]
    end
    
    subgraph Storage["데이터 저장소 레이어"]
        FS[파일 시스템<br/>- JSON 데이터<br/>- 이미지 데이터]
        DBStorage[데이터베이스<br/>- Books, Curriculums<br/>- Lessons, Units<br/>- Templates, Progress]
    end
    
    subgraph External["외부 서비스 및 하드웨어"]
        AISvc[AI 서비스<br/>- OpenAI API GPT-4o-mini<br/>- Anthropic API Claude]
        BrowserAPI[브라우저 API<br/>- Web Speech API STT/TTS<br/>- Web Bluetooth API]
        HW[하드웨어 디바이스<br/>- Orbit Reader 20<br/>- Arduino 기반 점자 디스플레이]
    end
    
    UI -->|HTTP/REST API<br/>WebSocket 향후| API
    API -->|Service Layer 호출| Services
    Services -->|Infrastructure Layer 호출| Infra
    Infra -->|데이터 저장/조회| Storage
    AIInfra -->|API 호출| AISvc
    UI -->|브라우저 API| BrowserAPI
    BrowserAPI -->|BLE 통신| HW
```
