## 시스템 개요

### 프로젝트 목적

시각장애 수험생을 위한 수능 학습 지원 시스템으로, 점자 디바이스와 음성을 활용한 접근 가능한 학습 환경을 제공합니다.

### 핵심 가치

1. **접근성 우선**: 시각장애 학습자가 독립적으로 학습할 수 있는 환경
2. **제작 효율성**: 제작 시간 단축을 통한 콘텐츠 확대
3. **개인화 학습**: AI 기반 맞춤형 추천 및 적응형 학습 경로

### 주요 기능

- **학습 관리**: 교재, 레슨, 단원 관리 및 학습 진행 상황 추적
- **점자 변환**: 한글 텍스트를 점자로 변환하여 점자 디바이스에 전송
- **음성 처리**: STT, TTS, 오디오-텍스트 동기화
- **문제 풀이**: 문제 표시, 답안 입력, 정답 확인, 오답 분석
- **복습 시스템**: 간격 반복 학습 알고리즘 기반 복습 큐 관리
- **커리큘럼 자동 생성**: 강의대본(HWP) 분석을 통한 커리큘럼 자동 생성
- **레슨 블록 시스템**: 강의를 블록 단위로 구조화하여 학습 경험 최적화
- **AI/ML 기능**: 추천 시스템, 생성형 AI, ML 기반 점자 변환

### 레이어별 역할

#### 1. 클라이언트 레이어
- **웹 앱 (React)**: 메인 사용자 인터페이스
- **확장 프로그램 (Chrome)**: 강의 동기화 및 알림
- **점자 디바이스 (BLE)**: 점자 출력 하드웨어

#### 2. API Gateway 레이어
- **FastAPI**: RESTful API 서버
- **라우터**: 도메인별 엔드포인트 관리
- **인증/인가**: 사용자 인증 및 권한 관리

#### 3. 서비스 레이어
- **비즈니스 로직**: 도메인별 서비스 구현
- **AI/ML 통합**: LangChain, Whisper, Sentence Transformers
- **외부 API 통합**: OpenAI, Google STT

#### 4. 데이터 레이어
- **SQLite**: 메타데이터 (교재, 레슨, 진행 상황)
- **MongoDB**: 레슨 블록 콘텐츠 (Document DB)
- **파일 시스템**: 원본 파일 (PDF, HWP)

## 주요 컴포넌트

### 1. 백엔드 API 서버

**기술**: FastAPI (Python 3.11+)

**주요 모듈**:
- **라우터** (`api/app/routers/`): API 엔드포인트 정의
- **서비스** (`api/app/services/`): 비즈니스 로직 구현
- **스키마** (`api/app/schemas/`): Pydantic 데이터 검증
- **모델** (`api/app/db/`): 데이터베이스 모델 정의

**핵심 기능**:
- RESTful API 제공
- 파일 업로드/다운로드
- 실시간 동기화 (WebSocket)
- 백그라운드 작업 처리

### 2. 프론트엔드 웹 앱

**기술**: React + TypeScript + Vite

**주요 모듈**:
- **페이지** (`apps/web/src/pages/`): 주요 화면 컴포넌트
- **컴포넌트** (`apps/web/src/components/`): 재사용 가능한 UI 컴포넌트
- **훅** (`apps/web/src/hooks/`): 커스텀 React 훅
- **서비스** (`apps/web/src/services/`): API 클라이언트
- **상태 관리** (`apps/web/src/store/`): Zustand 스토어

**핵심 기능**:
- 반응형 UI (모바일 우선)
- 점자 디바이스 연동 (Web Bluetooth API)
- 음성 인식/합성 (Web Speech API)
- 접근성 지원 (ARIA, 키보드 네비게이션)

### 3. 레슨 블록 시스템

**기술**: LangChain + OpenAI GPT-4o-mini + MongoDB

**주요 모듈**:
- **LangChain Flow** (`api/app/services/langchain_lesson_flow.py`): LLM 기반 블록 생성
- **규칙 기반 분해기** (`api/app/services/lesson_block_decomposer.py`): 패턴 매칭 분해
- **MongoDB 모델** (`api/app/db/mongodb_models.py`): 문서 스키마 정의

**핵심 설계 원칙**:
- **점자는 신호등**: 3셀 점자로 현재 상태만 표시
- **5가지 필수 요소**: 학습 목적, 점자 신호, 음성 범위, 사용자 인지, UI 동작
- **Document DB**: 레슨 단위 완결된 문서 저장

### 4. 커리큘럼 자동 생성 시스템

**기술**: Python + 정규식 + 의존성 분석

**주요 모듈**:
- **커리큘럼 생성기** (`api/app/services/curriculum_generator.py`): 강의대본 분석
- **템플릿 시스템** (`api/app/services/curriculum_template.py`): 과목별 템플릿
- **PDF 매칭** (`api/app/services/pdf_script_matcher.py`): 참조 정보 매칭

**핵심 기능**:
- HWP 파일 분석 및 구조 파싱
- 학습 단위 자동 생성
- 의존성 분석 및 학습 경로 생성
- JSON 파일 저장 (과목별 폴더)

### 5. AI/ML 서비스

**기술**: PyTorch, LangChain, Hugging Face, OpenAI

**주요 모듈**:
- **ML 기반 동기화** (`api/app/services/audio_sync_ml.py`): Whisper + Sentence Transformers
- **추천 엔진** (`api/app/services/recommendation_engine.py`): 콘텐츠 기반 필터링
- **생성형 AI** (`api/app/services/content_generator.py`): LangChain + GPT-4
- **점자 변환 ML** (`api/app/services/braille_ml.py`): KoBERT 기반 Seq2Seq

```
사용자
  ↓
[홈 화면] → 교재 선택
  ↓
[교재 목록] → 레슨 선택
  ↓
[레슨 화면] → 레슨 블록 조회 (MongoDB)
  ↓
[점자 디바이스] ← 점자 변환 ← 블록 콘텐츠
  ↓
[음성 재생] ← 오디오 동기화 ← 블록 타임스탬프
  ↓
[문제 풀이] → 답안 제출
  ↓
[정답 확인] → 오답 분석
  ↓
[복습 큐] ← 복습 스케줄링
```

```
제작자
  ↓
[HWP 파일 업로드] → API 서버
  ↓
[텍스트 추출] → hwp_extract.py
  ↓
[구조 파싱] → lecture_script_parser.py
  ↓
[커리큘럼 생성] → curriculum_generator.py
  ↓
[학습 단위 생성] → curriculum_template.py
  ↓
[DB 저장] → SQLite (Curriculum, LearningUnit)
  ↓
[JSON 저장] → data/curricula/{subject}/
  ↓
[임시 파일 삭제] → 자동 정리
```

### 3. 레슨 블록 생성 흐름

```
강의대본 입력
  ↓
[전처리] → 불필요한 기호/공백 정리
  ↓
[LLM 분해] → LangChain Flow (GPT-4o-mini)
  ↓
[JSON 파싱] → 정규식 기반 추출
  ↓
[스키마 검증] → Pydantic 검증
  ↓
[MongoDB 저장] → lessons 컬렉션
  ↓
[UI 전달] → 프론트엔드 조회
```

### 4. 추천 시스템 흐름

```

  ↓
[행동 프로파일링] → user_behavior_profiler.py
  ↓
[프로파일 생성] → 학습 패턴, 약점 주제
  ↓
[콘텐츠 임베딩] → Sentence Transformers
  ↓
[유사도 계산] → 코사인 유사도
  ↓
[추천 생성] → PersonalizedRecommender
  ↓

## 레슨 블록 아키텍처

### 설계 철학

**"점자는 신호등, 강의는 경험 문서"**

- 점자 디바이스 제약 (3셀)을 받아들이고, 오히려 "상태 신호"로 활용
- 강의를 블록 단위로 구조화하여 학습자가 항상 자신의 위치를 인지
- 각 블록은 독립적이면서도 전체 맥락 안에서 의미를 가짐

### 레슨 블록 구조

```
Lesson (MongoDB Document)
├── lesson_id: "korean_01"
├── lesson_title: "1강 [교과서_개념] 1, 2"
├── subject: "korean"
├── lesson_number: 1
├── blocks: [
│   ├── Block 1: {
│   │   ├── block_id: "B1"
│   │   ├── block_type: "orientation"
│   │   ├── braille_signal: "●○○"
│   │   ├── learning_intent: {...}
│   │   ├── audio_range: {start: "00:00:00", end: "00:05:23"}
│   │   ├── user_awareness: {...}
│   │   ├── ui_behavior: {...}
│   │   └── content: {...}
│   │   },
│   ├── Block 2: {...},
│   └── ...
│   ]
└── metadata: {...}
```

### 블록 생성 파이프라인

```
강의대본 (HWP/텍스트)
  ↓
[전처리]
  - 타임스탬프 제거
  - 공백 정리
  ↓
[LLM 분해] (LangChain Flow)
  - 프롬프트: DECOMPOSITION_PROMPT
  - 모델: GPT-4o-mini (temperature=0)
  - 출력: JSON 형식 블록 목록
  ↓
[JSON 파싱]
  - 정규식 기반 JSON 추출
  ↓
[Pydantic 검증]
  - LessonBlock 스키마 검증
  - 타입 안전성 보장
  ↓

  - lessons 컬렉션에 저장

## 데이터베이스 설계

### SQLite (메타데이터)

**용도**: 교재, 레슨, 단원, 진행 상황, 복습 큐 등 메타데이터 저장

**주요 테이블**:
- `books`: 교재 정보
- `lessons`: 레슨 정보
- `units`: 단원 정보
- `curricula`: 커리큘럼 정보
- `learning_units`: 학습 단위 정보
- `progress`: 학습 진행 상황
- `review_queue`: 복습 큐

**특징**:
- 관계형 데이터 구조
- 정규화된 스키마
- 빠른 조회 성능

### MongoDB (레슨 블록 콘텐츠)

**용도**: 레슨 블록 콘텐츠 저장 (Document DB)

**컬렉션**: `lessons`

**문서 구조**:
```json
{
  "_id": ObjectId("..."),
  "lesson_id": "korean_01",
  "lesson_title": "1강 [교과서_개념] 1, 2",
  "subject": "korean",
  "lesson_number": 1,
  "blocks": [
    {
      "block_id": "B1",
      "block_type": "orientation",
      "braille_signal": "●○○",
      "learning_intent": {
        "title": "강의 소개",
        "description": "이 강의의 목표를 이해한다"
      },
      "audio_range": {
        "start": "00:00:00",
        "end": "00:05:23"
      },
      "user_awareness": {
        "message": "강의가 시작되었습니다",
        "context": "오리엔테이션 단계"
      },
      "ui_behavior": {
        "autoPlay": true,
        "bookmarkable": true,
        "reviewable": true
      },
      "content": {
        "text": "여러분, 안녕하세요? ...",
        "key_points": [...]
      }
    }
  ],
  "metadata": {
    "createdAt": "2026-01-16T...",
    "updatedAt": "2026-01-16T..."
  }
}
```

**특징**:
- 레슨 단위 완결된 문서
- 블록은 레슨에 임베디드
- 유연한 스키마 (과목별 차이 허용)
- 단일 쿼리로 전체 레슨 조회

### 파일 시스템

**구조**:
```
data/
├── curricula/              # 커리큘럼 JSON (과목별 폴더)
│   ├── korean/
│   ├── math1/
│   └── english/
├── uploads/                # API 업로드 파일
├── lecture_scripts/        # 강의 대본 원본 (과목별 폴더)
│   ├── 수능특강_문학_2026/
│   ├── 수능특강_수1_2026/
│   └── 수능특강_영어_2026/
├── pdfs/                   # PDF 교재 원본
├── extracted/              # 추출된 텍스트 캐시
├── parsed/                 # 파싱된 데이터
└── datasets/               # 생성된 데이터셋
```

## 시스템 통합 흐름

### 엔드투엔드 학습 시나리오

```
1. 사용자 로그인
   ↓
2. 홈 화면 → 교재 선택
   ↓
3. 교재 목록 → 레슨 선택
   ↓
4. 레슨 상세 조회
   - SQLite: 레슨 메타데이터 조회
   - MongoDB: 레슨 블록 콘텐츠 조회
   ↓
5. 레슨 블록 순차 재생
   - 블록 1: 점자 신호 "●○○" → 점자 디바이스 출력
   - 블록 1: 오디오 재생 (00:00:00 ~ 00:05:23)
   - 블록 1: UI 상태 업데이트
   ↓
6. 문제 풀이
   - 문제 표시
   - 답안 입력
   - 정답 확인
   ↓
7. 오답 분석
   - 오답 패턴 기록
   - 복습 큐 추가
   ↓
8. 추천 시스템
   - 사용자 행동 분석
   - 다음 레슨 추천
```

### 제작자 워크플로우

```
1. HWP 파일 업로드
   ↓
2. 텍스트 추출 및 구조 파싱
   ↓
3. 커리큘럼 자동 생성
   - 학습 단위 생성
   - 의존성 분석
   - 학습 경로 생성
   ↓
4. 레슨 블록 생성 (선택)
   - LangChain Flow 실행
   - MongoDB 저장
   ↓
5. JSON 파일 저장
   - data/curricula/{subject}/
   ↓
6. 임시 파일 자동 삭제
```
