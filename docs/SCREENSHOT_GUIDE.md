# 캡처 추천 화면 가이드

## 개요

포트폴리오, 문서, 발표 자료에 사용하기 좋은 화면 캡처 추천 목록입니다.

---

## 🎯 필수 캡처 화면 (6개)

### 1. **단원 학습 화면 - 개념 뷰어** ⭐⭐⭐
**경로**: `/unit/:unitId` (개념 타입 단원)  
**우선순위**: 최우선

**캡처 포인트**:
- 개념 콘텐츠가 표시된 상태
- 이미지가 포함된 경우 (이미지 표시)
- 점자 키워드 패널이 열린 상태 (선택적)
- AI 설명 카드가 표시된 상태 (선택적)

**왜 중요한가?**
- 핵심 학습 화면으로, 앱의 메인 기능을 보여줌
- 텍스트, 이미지, 점자, AI 기능이 모두 보임
- 접근성 기능이 잘 드러남

**캡처 팁**:
- 모바일 화면으로 캡처 (실제 사용 환경)
- 개념 제목과 내용이 잘 보이도록
- 이미지가 있다면 포함

---

### 2. **단원 학습 화면 - 문제 풀이** ⭐⭐⭐
**경로**: `/unit/:unitId` (문제 타입 단원)  
**우선순위**: 최우선

**캡처 포인트**:
- 문제 지문과 선택지가 표시된 상태
- 답안 입력 인터페이스
- 답안 제출 후 결과 화면 (정답/오답)

**왜 중요한가?**
- 문제 풀이 기능을 시각적으로 보여줌
- 인터랙티브한 UI 요소가 많음
- 학습 평가 기능을 보여줌

**캡처 팁**:
- 문제가 완전히 보이도록 스크롤 조정
- 답안 선택 전/후 두 가지 상태 모두 캡처
- 결과 화면도 함께 캡처

---

### 3. **점자 키워드 패널** ⭐⭐
**경로**: `/unit/:unitId` → 점자 모듈 열기  
**우선순위**: 높음

**캡처 포인트**:
- 점자 모듈 오버레이가 열린 상태
- 핵심 키워드의 점자셀이 표시된 상태
- 현재 키워드 정보 (예: "1/3 시적")
- 이전/다음 버튼

**왜 중요한가?**
- 점자 디스플레이 연동 기능을 시각적으로 보여줌
- 접근성 기능의 핵심
- 독특한 UI 요소

**캡처 팁**:
- 모바일 화면으로 캡처
- 점자셀의 점 패턴이 잘 보이도록
- 키워드 텍스트와 점자셀이 함께 보이도록

---

### 4. **관리자 페이지 - 교재 관리** ⭐⭐
**경로**: `/admin` (교재 관리 탭)  
**우선순위**: 높음

**캡처 포인트**:
- 교재 목록이 표시된 상태
- 통계 카드 (전체 교재, 완료, 진행 중, 실패)
- 파싱 진행 중인 교재 (진행률 표시)
- 교재별 액션 버튼

**왜 중요한가?**
- 관리자 기능을 보여줌
- 파싱 상태 모니터링 기능
- 데이터 관리 인터페이스

**캡처 팁**:
- 여러 교재가 보이도록
- 파싱 진행 중인 교재 포함
- 통계 카드가 잘 보이도록

---

### 5. **관리자 페이지 - 템플릿 관리** ⭐⭐
**경로**: `/admin` (템플릿 관리 탭)  
**우선순위**: 중간

**캡처 포인트**:
- 템플릿 목록 (과목별 필터링)
- 템플릿 카드 (이름, 과목, 신뢰도)
- 템플릿 생성 버튼
- 과목 필터 버튼

**왜 중요한가?**
- 템플릿 관리 시스템을 보여줌
- 파싱 설정 관리 기능
- 관리자 도구의 일부

**캡처 팁**:
- 여러 템플릿이 보이도록
- 과목 필터가 활성화된 상태
- 템플릿 정보가 잘 보이도록

---

### 6. **교재 선택 화면** ⭐
**경로**: `/books`  
**우선순위**: 중간

**캡처 포인트**:
- 교재 목록 (번호가 매겨진 목록)
- 교재 카드 (제목, 과목, 연도, 강의 수)
- 파싱 상태 표시
- 키보드 단축키 안내

**왜 중요한가?**
- 사용자 플로우의 시작점
- 교재 선택 인터페이스
- 접근성 기능 (키보드 네비게이션)

**캡처 팁**:
- 여러 교재가 보이도록
- 선택된 교재가 하이라이트된 상태
- 파싱 상태 아이콘이 잘 보이도록

## 🎨 캡처 가이드라인

### 화면 크기
- **모바일**: 375px × 667px (iPhone SE) 또는 390px × 844px (iPhone 12)
- **태블릿**: 768px × 1024px (iPad)
- **데스크톱**: 1920px × 1080px (Full HD)

### 권장 캡처 방법
1. **브라우저 개발자 도구 사용**
   - Chrome DevTools → Device Toolbar
   - 모바일 화면 크기로 설정
   - 스크린샷 캡처

2. **실제 디바이스 사용**
   - 모바일 기기에서 직접 캡처
   - 더 현실적인 화면

3. **전체 페이지 캡처**
   - 스크롤이 필요한 경우 전체 페이지 캡처
   - 또는 주요 섹션만 캡처

### 캡처 시 주의사항
- ✅ 실제 데이터가 표시된 상태로 캡처
- ✅ 중요한 UI 요소가 잘 보이도록
- ✅ 텍스트가 읽기 쉬운 크기로
- ✅ 색상 대비가 충분한지 확인
- ❌ 개인정보나 민감한 정보 제거
- ❌ 로딩 중 화면은 피하기
